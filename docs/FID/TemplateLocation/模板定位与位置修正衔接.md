# 模板定位与位置修正衔接

更新时间：2026-07-23

## 当前边界

模板定位输出位置修正可消费的主位姿：`x`、`y`、`angle`（角度制）、`angleDeg`、`scale`
和 `pose`。多匹配时顶层位姿取 HALCON 返回的第一最佳结果，`primaryMatchIndex=0`；
全部候选保存在 `matches`。

位置修正运行链路已经接通：

- 工具级位置修正保存 `referencePose`，从当帧上游结果读取 `runPose`，输出双向变换矩阵；
- 基准图位置修正使用私有模板定位器，固定 ID 为 `reference.positionCorrection`，显示为
  `0 基准图`；
- `ToolEngine::runTools` 每帧重建 `toolResultsById` 和 `positionCorrectionsById`，并给结果
  写入 `frameId`；
- 消费端校验稳定来源 ID、工具类型和帧 ID，不读取上一帧结果；
- 当前完整消费者是颜色比较与 Blob 有无，其他工具链尚未接入。

## 三类节点的职责

- 模板定位工具：真实位姿生产者，输出 `x/y/angle/scale`，不计算修正矩阵。
- 工具级位置修正：纯姿态变换节点；可订阅前置模板定位，也可订阅有效的基准图位置修正，
  保存基准姿态并计算矩阵，自身不做模板匹配、不保存模板 ROI。
- 基准图位置修正：方案级组合节点，内部拥有私有模板定位器并输出位姿与修正矩阵。

基准图位置修正建立产品级全局坐标系，工具级位置修正可以建立局部对象坐标系。下游每次只选择
一个最终位置修正来源；选择局部绝对矩阵后不得再次叠加全局矩阵。

## 基准姿态与运行姿态

工具级位置修正内部存在两组 X/Y/角度/尺度：

- `referencePose`：点击“创建基准”时，在基准图上下文中执行同一来源后冻结；
- `runPose`：每帧从同一来源的当帧结果读取。

两组姿态必须来自同一稳定来源。X、Y、角度必须是有限数值；显式提供的尺度必须是有限正数，
缺失尺度才按 `1.0` 兼容。非法输入分别返回 `invalid_reference_pose`、`invalid_run_pose`
或 `invalid_pose_scale`，不得静默回退为零。

## 接入与执行顺序

1. 模板定位来源必须位于工具级位置修正之前，消费工具必须位于所选工具级位置修正之后；
   基准图固定来源由引擎在普通工具之前执行。
2. 工具级来源使用稳定 `toolId`；基准图来源使用固定 ID
   `reference.positionCorrection`，显示文案不参与运行引用。
3. 创建基准使用专用基准图上下文执行来源，并保存 `referencePose`。
4. 每帧使用 HALCON 变换从 `referencePose` 和 `runPose` 生成
   `referenceToRunHomMat2D` 与 `runToReferenceHomMat2D`。
5. 下游从 `positionCorrectionsById` 读取所选来源，用 HALCON ROI 变换接口生成当帧临时 ROI；
   原始基准 ROI 不写回。
6. 每帧动态结果容器必须从空对象开始。来源结果的 `toolId`、`toolType` 或 `frameId`
   不匹配时立即失败。

## 多匹配约束

位置修正默认消费模板定位的最佳结果。存在多个相同目标时，应先通过搜索 ROI、数量判定或最低得分
保证第一结果稳定；需要编号或最近邻策略时，应新增明确策略，不能静默随机选择。

## 失败传播

- 上游执行失败、未找到或数量判定 NG：位置修正返回来源错误，不沿用上一帧位姿。
- 来源不存在或身份不符：返回明确的 missing/invalid 错误。
- 来源帧与当前帧不一致：返回 `source_frame_mismatch` 或
  `position_correction_frame_mismatch`。
- 基准姿态未创建：返回 `reference_pose_missing`。
- 位置修正失败时，下游不得标记 `positionCorrectionApplied=true`。
