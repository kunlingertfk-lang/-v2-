# 模板定位 UI 与交互设计

## 1. 产品边界

模板定位是独立的 `TemplateLocation` 工具，用基准图中的形状模板在运行图中定位单个最佳目标。它输出目标的 X、Y、角度、缩放和得分，不承担“位置修正”工具的基准/运行姿态差值计算。

视觉基调沿用现有工业工作台：左侧浅色参数区、右侧深色图像画布、橙色主操作、蓝色搜索区域、绿色匹配结果。参数与状态应能通过标题和字段快速扫描，不增加装饰性卡片。

## 3. 正常交互

1. 打开工具时显示方案基准图；没有基准图时禁止模板绘制、创建模板和测试，并提示“请先设置基准图”。
2. 模板矩形和模板多边形互斥。按钮 checked 仅表示当前绘制模式；退出绘制不删除已保存 ROI。
3. 用户绘制模板 ROI 后，模板状态变为“需要创建”；点击“创建模板”执行一次 HALCON 建模，成功后显示橙色模型轮廓及自动参数结果。“删除模板”清除模型有效状态和模型轮廓，但保留模板 ROI，方便重新创建。
4. 搜索区域按“全局、矩形、圆形、多边形”排列且互斥，图标组靠右对齐。选择矩形、圆形或多边形后按钮持续高亮；完成一次绘制后仍保持绘制态，下一次绘制直接替换上一次 ROI，不需要重复点击工具按钮。未设置搜索 ROI 时按整张运行图搜索。
5. “基准图测试”对基准图运行一次；“测试运行”进入连续运行；“退出测试”返回编辑态；“完成”校验并保存配置。
6. 找到目标时显示绿色匹配轮廓、中心十字，并在每一个匹配旁显示序号和匹配得分；底部结果栏固定为约两行文字高度，显示最佳结果的 X/Y、角度、缩放、得分和耗时。未找到显示正常 NG；输入或 HALCON 异常显示错误状态。
7. 重新打开恢复 ROI、参数和模型状态，但不自动进入任何 ROI 绘制状态。

## 4. 参数和显隐

### 基础页

| 参数 | 范围与默认值 | 行为 |
| --- | --- | --- |
| 模板 ROI | 矩形/多边形 | 保存归一化坐标 |
| 搜索 ROI | 全局/矩形/圆形/多边形 | 保存归一化坐标；局部模式支持连续覆盖绘制 |
| 最低得分 | 0–100，默认 50 | 传给匹配算子前换算为 0–1 |
| 角度范围 | -180°–180°，默认 -45°–45° | 最小值不得大于最大值 |
| 缩放范围 | 10%–200%，默认 100%–100% | 最小值不得大于最大值 |
| 极性 | 考虑/忽略局部/忽略全局 | 默认考虑极性 |
| 对比度模式 | 自动/手动 | 默认自动 |
| 最大查找数 | 1–100，默认 1 | 控制 `find_scaled_shape_model` 的 `NumMatches` |
| 数量判定 | 最少/最多，默认 1–最大查找数 | 必须满足最少 ≤ 最多 ≤ 最大查找数 |
| 定位点 | 质心/自定义点 | 默认质心；自定义点在基准图上点击选择 |

### 全部页

- 模板卡片显示可选的“屏蔽区域”矩形、圆形、多边形和“清除”操作，三种绘制方式互斥且单次仅保存一个屏蔽区。屏蔽区仅从模板建模 Region 中扣除，修改或清除后已有模型变为“需要重新创建”；基础页隐藏该行但不清除已保存配置。
- 自动对比度时向 HALCON 传入 `Contrast="auto"`、`MinContrast="auto"`；手动 `Contrast`、`MinContrast` 的标签和输入框同时禁用，并以深灰文字、中深灰底色和深灰边框突出自动接管状态。建模完成后只读显示“Contrast：自动”、实际 `MinContrast` 和实际金字塔层级。HALCON 20.11 不提供数值型自动 `Contrast` 回读。
- 手动对比度时显示 `Contrast` 和 `MinContrast`；两者范围为 1–255，且必须满足 `MinContrast < Contrast`。
- 金字塔层级为自动或 1–10；亚像素为 `least_squares` 或关闭；贪婪度为 0.0–1.0，默认 0.5；超时默认 2000 ms。
- 修改模板 ROI、角度、缩放、极性、对比度或金字塔参数后，已有模型变为“需要重新创建”。
- 最大查找数可设置为 1–100；结果列表按 HALCON 返回顺序保存，画布显示每个匹配轮廓、中心及“序号 + 得分”标签。
- 最大重叠率为 0–100%，默认 50%，对应 `find_scaled_shape_model.MaxOverlap`。
- 右侧匹配结果采用可折叠底部抽屉：默认仅显示“匹配结果（N）”摘要，展开后固定显示约 3 行并通过滚动条访问全部结果，避免结果数较多时把图像区、状态栏或底部动作按钮顶出屏幕。表格显示序号、X、Y、角度、缩放和得分；点击结果行时当前目标加粗，其他目标弱化。
- 模型磁盘缓存命中时显示“已加载持久缓存”，签名变化自动重建；删除模板同时清除缓存。
- ROI 图标统一为 24px 深灰线性 SVG；搜索区顺序固定为全局、矩形、圆形、多边形，checked 状态使用橙色边框和浅橙背景。图标按钮为紧凑等宽尺寸并整体靠右；“删除模板”与上方模板 ROI 图标组等宽、右边缘对齐。

## 5. 状态与校验

| 场景 | 状态/提示 |
| --- | --- |
| 无基准图 | `no_reference_image` / 请先设置基准图 |
| 模板 ROI 缺失 | `no_template_region` / 请先绘制模板区域 |
| ROI 无效 | `invalid_template_region` 或 `invalid_search_region` |
| 屏蔽区无效或不与模板相交 | `invalid_template_mask` |
| 屏蔽后有效模板面积不足 | `template_masked_empty` |
| 参数范围错误 | `invalid_parameter`，定位到对应字段 |
| 模板需要重建 | `model_dirty` / 参数已改变，请重新创建模板 |
| 删除模板 | 模型状态和模型轮廓清空，保留模板 ROI，测试按钮等待重新建模 |
| 未找到 | `not_found`，执行成功但结果 NG |
| HALCON runtime、license、符号异常 | 明确 HALCON 错误，不允许降级 |

普通 ROI、建模和测试按钮不得触发 Dialog 的 `accept`、`reject` 或程序退出。
