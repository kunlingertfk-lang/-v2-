# 工具列表复制与删除实施规划

## 目标

完善“方案编辑 - 工具”页面顶部预留的三个图标按钮，依次提供“复制工具”、“删除选中工具”和“删除所有工具”能力，并保证工具配置、预览快照、选中状态和方案落盘始终一致。

## 交互约定

- 三个按钮的鼠标悬停提示分别为：`复制工具`、`删除选中工具`、`删除所有工具`。
- 工具列表为空时，三个按钮全部禁用；有工具时全部启用。
- 复制项插入原工具后方并自动选中，不弹出确认框。
- 删除选中工具和删除所有工具都必须二次确认，确认框默认选中“否”。
- 删除选中工具后，优先选中原位置的下一项；删除末项时选中新的末项；列表为空时恢复基准图预览。

## 数据规则

- 复制 `ToolConfig` 的全部字段，但必须用 `QUuid` 生成新的稳定 `toolId`。显示名、算法参数、判定规则、ROI 及外部模型/模板路径原样保留。
- 原工具有有效 `ToolPreviewSnapshot` 时同步复制，并把快照和其 `ToolResult` 的 `toolId` 改为新 ID。
- 删除工具时同步删除以该 `toolId` 为键的预览快照。
- 单项删除前递归检查所有后续工具 `params` 中的 `positionCorrectionSourceId`、`producerId` 和 `referencePoseSourceId`。发现精确 ID 引用时阻止删除并列出引用者，不自动改写或禁用下游工具。
- 复制和删除都立即通过 `SchemeStore` 保存当前方案；落盘失败时恢复操作前的工具、快照和选中状态。
- 顶部“保存”成功落盘后立即同步 `MainWindow` 的工具链内存状态和工具表，不再依赖输出页“完成”才生效；该同步不重复写盘。

## 实施路径

1. 调整 `ToolsDialog.ui` 按钮语义、图标和 tooltip。
2. 在 `ToolsDialog` 中实现工具复制、依赖扫描、单项删除、全部删除和工具栏启用状态刷新。
3. 新增专用清空图标并登记到 Qt 资源文件。
4. 新增独立 smoke，在临时方案目录验证交互、依赖保护、保存回显和回滚。
