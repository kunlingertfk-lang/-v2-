# 注册目标检测提示词规范

本文档用于规范“注册目标检测”后续开发提示词。当前工具按独立新工具处理，内部链路暂沿用 `RegisteredClassificationDetection` 命名以保持配置兼容；用户可见文案统一为 `注册目标检测`。第一阶段只完整复刻现有“注册分类”主配置 UI、入口、保存回显和占位运行闭环；检测专属功能、真实训练、真实数据集落盘和模型生成均不属于当前阶段。

## 固定上下文

后续注册目标检测开发应默认基于以下上下文：

```text

根目录 AGENTS.md 是最高约束。
FID 公有约束 docs/FID/Function_Docs.md 是功能算子公共规范。
注册目标检测开发必须同时遵守 AGENTS.md 和 docs/FID/Function_Docs.md。
视觉核心算法必须基于 HALCON；当前 UI 复刻阶段不接入算法。

注册目标检测是独立工具链：
```

## 当前阶段范围

In:

- 工具库入口可见，用户可见文案为 `注册目标检测`。
- 能打开 `RegisteredClassificationDetectionDialog`。
- 主对话框 UI 复刻现有注册分类主配置对话框：顶部标题栏、左侧参数区、右侧图像预览区、底部动作按钮。
- 左侧包含 `基础 / 全部` 分段、`模型训练`、`检测区域`、`参数设置`、`结果判断`。
- 保存和回显使用 `ToolConfig.params.registeredClassificationDetection` 与 `judgeRule`。
- 检测区域默认全屏，支持矩形 ROI UI 编辑、保存和回显。
- 位置修正默认关闭并禁用，tooltip 固定为 `位置修正补偿尚未实现，当前版本默认关闭。`
- `注册训练` 后续应打开独立的 `RegisteredClassificationDetectionTrainingDialog`，不再复用注册分类训练窗口。
- 训练窗口标题和主配置窗口标题使用 `注册目标检测`。
- 训练窗口中已绘制的模板 ROI 必须参考注册分类训练窗口显示编号标注，编号从 `1` 开始，与目标计数一致。
- 缩略图状态栏的 `全部 / 标注 / 未标注` 过滤下拉不得做成普通按钮样式；应参考注册分类训练窗口使用深底浅字、高对比边框和右侧独立下拉提示区，展开列表也必须保持高对比可读。
- 右侧训练参数区不得被大块空白分隔；`添加注册图`、`标注图像`、`目标列表`、检测专属参数和底部按钮应形成紧凑连续的工作流。
- `模型管理` 可暂时沿用现有注册分类模型管理占位窗口，直到注册目标检测模型管理另起专项设计。
- 测试运行在后端未接入时返回 `backend_not_implemented`，不得伪造 OK/NG。

Out:

- 不修改现有注册分类 Dialog、Adapter、Runner 行为。
- 不新增注册目标检测 Adapter 或 HALCON Runner。
- 不实现检测专属算法、真实 HALCON 训练、真实数据集落盘或模型生成。
- 不把注册分类训练窗口改造成多模式窗口，不在 `RegisteredClassificationTrainingDialog` 中堆叠注册目标检测分支。
- 不支持 `.scbin`。
- 不引入 OpenCV、自写算法、AI 推理链路或第三方分类库作为核心算法。

## 注册目标检测训练窗口专项提示词

```markdown
## 控件功能

### 添加注册图

- `相机抓图`：优先使用 `CameraFrameProvider::currentFrame()`；当前帧为空时可沿用注册分类训练窗口的基准图兜底逻辑；仍为空则显示明确状态。
- `存图导入`：若当前项目没有存图库数据源，按钮保留但禁用或点击提示 `存图导入暂未接入`。
- `外部导入`：打开文件选择，支持常见图片格式；导入成功后显示在左侧大图，并添加缩略图。
- 无图时，矩形/多边形标注按钮禁用或点击提示 `请先添加注册图`。

### 左侧图像浏览区

- 显示当前注册图。
- 支持上一张/下一张循环切换。
- 底部显示 `全部` 过滤下拉、`当前：x/y`、`已标注：n`。
- 过滤下拉包含 `全部`、`标注`、`未标注` 三项；切换后只显示当前条件对应的注册图缩略图，并同步当前图、当前序号、目标计数和预览区。
- 过滤下拉本体需要有明确的下拉提示区域，不得视觉上像普通按钮；允许深灰底白字，但必须满足高对比可读性。
- 缩略图悬浮时边框高亮，右上角显示单图删除图标；点击后删除该注册图及其 ROI 标注，并刷新缩略图、当前图、目标计数、目标预览和无图状态。
- 缩略图区右上角提供 `删除全部注册图` 图标；点击弹出确认删除全部注册图提示框，确认后删除全部注册图和 ROI，取消不做任何修改。
- 删除全部后训练窗口进入无图状态：预览区清空、ROI 按钮退出并禁用、缩略图为空、底部状态提示 `请先添加注册图`。
- 鼠标移动时更新 `X/Y/R/G/B`；无图时显示 `--`。
- 切换图片时同步显示该图已有目标框 overlay。

### 标注图像

- `矩形框选`：有图后可进入连续矩形 ROI 绘制模式，按钮保持高亮，可连续绘制多个矩形 ROI。
- `多边形框选`：有图后可进入连续多边形 ROI 绘制模式，按钮保持高亮，可连续绘制多个多边形 ROI。
- 两个标注按钮互斥；切换模式时另一个按钮取消高亮；再次点击当前高亮按钮退出绘制。
- 绘制完成后，ROI 写入当前目标 `Target`。
- 绘制完成后，ROI 在预览区显示连续 ID 编号；切换图片、重新显示当前图像或新增 ROI 时编号必须刷新。
- 矩形 ROI 和多边形 ROI 都必须有编号；多边形 ROI 的编号位置使用多边形外接矩形左上附近。
- 正在绘制时切换图片或目标，应退出绘制状态，避免后续 ROI 写入错误目标。
- 不显示、不实现 `全屏框选`。

### 目标列表

- 默认目标为 `Target`。
- 第一版不显示 `+ 新建`；如后续需要多目标类型，再另起设计。
- 第一版不显示删除目标按钮；如后续保留删除，必须二次确认并只删除目标及其标注。
- `重命名`：修改目标名；空名或重复名必须提示错误。
- `预览目标 ROI`：进入或退出目标 ROI 预览页，展示当前目标所有 ROI。
- 目标 ROI 预览页中的每个 ROI 卡片必须提供删除当前 ROI 图标；点击后删除该 ROI，并刷新预览卡片、ROI 编号、目标计数和缩略图标注状态。
- 计数格式为 `目标总数 / 图像总数`，例如 `1 / 1`。

### 检测专属参数

- `角度使能`：开关可切换，会话内保存，默认关闭。
- `最优模型分辨率设置使能`：开关可切换，会话内保存，默认关闭。
- 当前不写入真实训练配置；后续接训练时再设计持久化字段。

### 开始训练

- 无注册图时显示 `请先添加注册图`。
- 有图但无任何标注时显示 `请先标注目标`。
- 有图且有标注时显示 `训练算法未接入，当前仅完成 UI 标注闭环。`
- 不生成模型，不写真实数据集，不把状态改成已注册。
```

```text
version = 1
paramMode = "basic" | "all"
modelPath
modelName

roiNormalized
enablePositionCorrection = false
positionCorrectionSource = "1 基准图.位置修正信息"
```

```text
judgeType = "all_ok" | "any_ok"
judgeTypeText = "所有检测区域输出结果为 OK" | "任意检测区域输出结果为 OK"
```
