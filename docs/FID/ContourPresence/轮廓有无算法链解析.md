# 轮廓有无算法链解析

> 功能：轮廓有无（`ToolType::ContourPresence`）  
> 核对日期：2026-07-23

## 1. 功能定位与链路

轮廓有无从参考图模板区域提取 XLD 轮廓，建立 HALCON scaled shape model XLD，再在运行图检测域中搜索相似轮廓。

```text
ToolLibraryDialog(ContourPresence)
  -> ContourPresenceDialog
  -> ToolConfig + runtimeContext(referenceTest)
  -> ContourPresenceAdapter
  -> ContourPresenceHalconRunner
  -> PatternPresenceHalconApi（共享动态 HALCON 接口）
  -> ToolResult / overlays / payload
```

## 4. 算法流程

1. 校验运行图、参考图、图像类型、模板来源、模板/检测 ROI。
2. 动态加载 HALCON，并确认 XLD 提取和 XLD shape model 所需符号存在。
3. 将参考图转灰度并裁取模板矩形/多边形区域。
4. 提取模板 XLD：
   - 自动阈值模式优先 `edges_sub_pix`；
   - 手动阈值可先 `threshold + connection + gen_contour_region_xld`；
   - `segment_contours_xld` 分段；
   - `select_contours_xld` 按最小链长过滤；
   - 必要时在可用路径之间回退，并把模式写入 payload。
5. `create_scaled_shape_model_xld` 建立轮廓模型。
6. 对运行图应用矩形或多边形检测域。
7. `find_scaled_shape_model` 搜索位姿与得分。
8. 获取模型轮廓，按 row/column/angle/scale 做刚体和缩放变换，生成匹配轮廓/框。
9. `judgeBasis` 支持 presence、score 及其组合语义；参考图测试有独立诊断字段。
10. 清理 shape model、XLD、tuple 并返回。

主要 HALCON 接口：`edges_sub_pix`、`threshold`、`connection`、`gen_contour_region_xld`、`segment_contours_xld`、`select_contours_xld`、`create_scaled_shape_model_xld`、`find_scaled_shape_model`、`get_shape_model_contours`、`vector_angle_to_rigid`、`hom_mat2d_scale_local`、`affine_trans_contour_xld`。

## 5. 参数映射要点

- `featureScale` 映射亚像素边缘提取 sigma。
- `speedScale` 映射 shape matching greediness/搜索速度。
- `scaleMode=auto` 可对默认 100%..100% 范围作自动扩展；非法范围回退 0.9..1.1。
- `thresholdType` 决定极性/阈值方式；未知值回退并在 payload 标记。
- `minChainLength` 决定保留轮廓的最短链。
- `minScore` 和 `scoreThreshold` 可接受 0..1 或百分数式输入，Adapter 归一化为 0..1。

## 6. 输出

- `count`：匹配数量；
- `score`：最佳匹配分；
- overlays：模板/检测 ROI、匹配框、变换后的模型轮廓、结果文字；
- payload：`templateContourCount/Lengths/PointCount`、`shapeModelOperator`、`matches`、`matchScores`、`bestRow/Column/Angle/Scale/Score`、`threshold*Used`、`chainModeUsed`、`scale*Used`、`timeout*`、`detectRegionFallback`、`okNgReason`。

## 7. 错误与真实边界

错误包括：

- `image_empty`、`reference_image_empty`
- `unsupported_image_type`
- `unsupported_template_source`
- `invalid_template_roi/polygon`、`unsupported_template_roi`
- `invalid_detect_roi/polygon`、`unsupported_detect_roi`
- `template_contour_extraction_failed`
- `halcon_so_not_found`、`halcon_load_failed`、`halcon_symbol_missing`
- HALCON 异常

真实边界：

- 模板来源仅支持参考图。
- 模板支持矩形/多边形；检测支持矩形/多边形。自由/圆等类型可能退到包围矩形并明确写入 `detectRegionFallback`，不能视为原形状生效。
- 位置修正已接入公共 Consumer 和 HALCON Region 路径，详见本文末尾 2026-07-24 记录。
- `sortMode` 未应用。
- mask UI/配置未接到 Runner。
- timeout 不是 HALCON 强制取消。

## 8. 验证建议

当前没有独立轮廓有无 smoke。建议覆盖矩形/多边形模板与检测域、自动/手动阈值、轮廓链长、缩放角度、正负样本、低分、参考图测试、回退路径、缺 XLD 符号和 HALCON/license 异常。
## 2026-07-24 位置修正接入

- Dialog 使用公共位置修正配置格式，保存稳定来源 ID，并通过完整方案前缀执行配置窗口测试。
- Adapter 使用 `PositionCorrectionConsumer::resolve()` 取得统一 Context。
- Runner 在整图绝对坐标创建矩形/多边形基准 Region，以 HALCON `affine_trans_region`、`clip_region`、`reduce_domain` 限定轮廓匹配搜索域；匹配和模型轮廓坐标按整图坐标输出。
- 修正检测 ROI、匹配轮廓、匹配原点共享同一矩阵，运行态显示时清除配置态 ROI。
- Dialog 已提供 PC 图片离线测试，矩形/多边形 ROI 修改后立即重测并在退出时清理运行层。
- 验证：主工程影子 qmake/make、`presence_ocr_position_correction_contract_smoke` 通过。
