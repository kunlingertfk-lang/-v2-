# 注册分类提示词规范

## 1. 当前唯一有效基线

任何注册分类任务开始前必须阅读：

- `AGENTS.md`
- `docs/FID/Function_Docs.md`
- `docs/FID/RegisteredClassification/registered_classification_function_implementation.md`
- `docs/FID/RegisteredClassification/注册分类算法当前实现说明.md`
- 对应 Task brief、最终 report 和已批准的 KNN V2 设计/计划

当前实现固定为：

```text
modelType = halcon_knn_registered_classification
schemaVersion = 2
featureVersion = halcon_registered_feature_v2
featureLength = 59
```

历史文档里出现的 MLP、DL、28 维特征或 `model.gmc` 不能当作当前要求。后续代码、配置、测试和文档禁止重新引入 MLP/DL 兼容：不得新增 MLP/DL 推理分支、旧模型直接读取、旧特征回退、权重转换、伪造兼容模型或静默降级。已有 schema 1/`model.gmc` 只允许作为 legacy 记录被列出并引导重新训练，不能直接运行。

## 2. 工作边界

### 2.1 必须保持

- HALCON 是视觉和分类核心；OpenCV 仅做 `cv::Mat` 输入、测试图生成和必要的格式桥接。
- Feature V2 的 59 个名称、顺序、分组、权重、归一化和距离公式不可改变；改变即必须升级 featureVersion。
- 样本 KNN 和类别中心 KNN 必须同时存在、同时加载、同时校验。
- 所有 HALCON 句柄、tuple、图像和区域对象必须使用 RAII/作用域清理；成功创建/读取的 KNN 句柄只清理一次。
- 位置修正字段可以保存、回显、透传，但当前绝不应用；payload 必须表达 `positionCorrectionApplied=false`。
- 新训练和模型管理、训练会话、日期目录、重新训练的原子替换闭环必须保持。

### 2.2 禁止

- 禁止使用自写分类器、OpenCV 分类器、模板匹配、形状模型匹配、DL/ONNX/RKNN/TensorRT 或其他非 HALCON 核心算法替代 KNN。
- 禁止把训练多边形 ROI 转成外接矩形；必须保留真实多边形点并由 HALCON `gen_region_polygon_filled` 生成区域。
- 禁止单独使用 `model.gnc` 或 `class_centers.gnc` 运行；不完整包必须返回 `model_package_incomplete`。
- 禁止把 `topK` 当作内部拒识计算数量；内部仍需完成 Top2 和全类别比较。
- 禁止把 UNKNOWN 当成算法错误；拒识是成功推理后的 NG。
- 禁止修改 `docs/FID/RegisteredClassification/tempFunc.md` 或用户未提交的样例资产，除非任务明确要求。

## 3. Feature V2 固定合同

| 组 | 维度 | 权重 |
| --- | ---: | ---: |
| shape | 13 | 0.35 |
| occupancy | 16 | 0.25 |
| gray | 18 | 0.15 |
| color/Lab | 6 | 0.15 |
| texture | 6 | 0.10 |

总长度固定为 59。每个特征组按组权重缩放，完整向量 L2 归一化，HALCON KNN `normalization=false`。非有限、缺失、错误长度或零范数不得被默认值掩盖，必须返回 `invalid_feature_value`。

训练 ROI：`full`、`rectangle`、`polygon`。矩形使用 `gen_rectangle1`，多边形使用 `gen_region_polygon_filled`，少于三个点拒绝。多边形候选、边界带和质心必须基于真实区域。

在线检测 ROI：主 Dialog 当前只有 `full`、`rectangle`。不要凭空扩展在线多边形配置，也不要在文档中把训练 ROI 与检测 ROI 混为一谈。

## 4. 双 KNN 固定参数和文件

训练和推理必须理解为一对模型：

| 模型 | 文件 | 样本语义 |
| --- | --- | --- |
| 样本 KNN | `model.gnc` | 每个有效注册 ROI 一个样本 |
| 中心 KNN | `class_centers.gnc` | 每个类别一个 L2 归一化中心 |

固定参数：

```text
method       = classes_distance
normalization = false
num_trees    = 4
num_checks   = 0
epsilon      = 0.0
sampleWeight = 0.70
centerWeight = 0.30
```

样本 KNN 的 `k` 为有效样本总数，中心 KNN 的 `k` 为类别数，`max_num_classes` 为类别数。`class_stats.json` 必须与 metadata 的类别和样本总数一致。

类内半径：

```text
radius = max(maxDistance * 1.10,
             meanDistance + 2.5 * populationStdDev)
radius = clamp(radius, 0.10, 2.00)
```

少于三样本时 `radiusEnabled=false` 且 radius 为 0；三样本及以上才启用半径。

## 5. 融合、拒识和 payload

```text
similarity = clamp(1 - distance^2 / 2, 0, 1)
sampleSimilarity = 100 * similarity(dSample)
centerSimilarity = 100 * similarity(dCenter)
score = 0.70 * sampleSimilarity + 0.30 * centerSimilarity
```

默认阈值为 `minSimilarity=80`、`minMargin=8`；工具配置可在 `[0,100]` 内覆盖
运行时阈值。拒识顺序和状态固定为：

1. score 小于 `minSimilarity`：`classification_rejected_low_similarity`。
2. Top1 与 Top2 分差小于 `minMargin`：`classification_rejected_ambiguous`。
3. 启用半径且中心距离超过半径：`classification_rejected_out_of_radius`。

三种拒识都必须返回：

```text
success = true
ok = false
predictedLabel = UNKNOWN
predictedClassId = -1
```

并保留最佳已知候选、`bestCandidateClassId`、`bestCandidateLabel`、score、TopK、距离、半径、阈值和 `rejectionReason`。只有输入、模型、HALCON、ROI 或特征链路失败才返回 `success=false`。

## 6. 配置和模型目录

配置至少保持：

```text
params.registeredClassification.version = 2
params.registeredClassification.modelType = halcon_knn_registered_classification
params.registeredClassification.modelPath = 完整模型包目录
params.registeredClassification.detectRegionType = full | rectangle
params.registeredClassification.roiNormalized
params.registeredClassification.topK = 1
params.registeredClassification.minSimilarity = 80
params.registeredClassification.minMargin = 8
params.registeredClassification.enablePositionCorrection
params.registeredClassification.positionCorrectionSource
```

模型包：

```text
ModelFiles/RegisteredClass/yyyyMMdd/model_HHmmss_zzz/
├── model.gnc
├── class_centers.gnc
├── metadata.json
├── class_stats.json
├── training_report.json                 # 训练器生成
└── training_session/                    # 可选
    ├── session.json
    └── images/*.png
```

运行最小包必须包含 `metadata.json`、两个 `.gnc` 和 `class_stats.json`；
`training_report.json` 不属于运行最小包校验项，`training_session/` 仅用于恢复重新训练。

新注册创建新的日期/时间目录。模型管理重新训练使用原模型目录，先临时写入、完整校验，再原子替换；训练失败必须保留旧包。

## 7. UI、Adapter 和模型管理提示词模板

### 7.1 UI 任务

```markdown
基于当前注册分类 KNN V2 文档维护 UI。只处理入口、配置保存/回显、训练窗口、模型管理、ROI 交互和结果展示，不改算法合同。

必须保持：modelType=halcon_knn_registered_classification、schemaVersion=2、59 维 Feature V2，且 minSimilarity/minMargin 默认值为 80/8、运行配置范围为 0..100。
主检测 ROI 只允许 full/rectangle；训练 ROI 可为 full/rectangle/polygon，并把真实 polygon 点传给训练请求。
位置修正只保存和透传，当前不应用。
旧 schema 1/MLP 包可列出并提供重新训练，但 use/run 必须禁用；有训练会话则恢复图像、类别和 ROI，无会话则提示重新添加。
不要添加 MLP/DL 兼容或 model.gmc 运行路径。
运行对应 dialog smoke，确认保存、回显、模型选择、legacy 禁用和 UNKNOWN 展示。
```

### 7.2 后端任务

```markdown
基于当前注册分类 KNN V2 文档维护 HALCON Adapter/Runner/训练后端。

只使用 HALCON Feature V2 59 维、样本 KNN model.gnc、中心 KNN class_centers.gnc 和 class_stats.json。
固定参数 method=classes_distance、normalization=false、num_trees=4、num_checks=0、epsilon=0.0。
使用 score=0.70*sampleSimilarity+0.30*centerSimilarity，固定 80/8 阈值和三种拒识状态。
拒识必须 success=true、ok=false、UNKNOWN、classId=-1，并保留 candidate payload。
所有 HALCON 资源采用 RAII；任何异常路径不得泄漏句柄。
legacy 只允许 inspection/retrain，不允许直接运行。禁止重新引入 MLP/DL 兼容。

```
