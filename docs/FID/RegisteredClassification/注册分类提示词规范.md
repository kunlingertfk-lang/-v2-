# 注册分类提示词规范

本文档用于规范后续基于海康官方“注册分类”功能描述，在当前 Qt 工业视觉工程中实现注册分类工具时的提示词写法。目标是把海康交互语义映射到本项目可落地的 HALCON runner 链路，同时明确当前阶段边界、模型格式限制、UI 约束、配置字段和验证要求。

## 提示词分层原则

注册分类后续开发必须把 UI 和后端分开提示、分开实现、分开验证。除非用户明确要求一次性联调，否则不要用一个提示词同时要求完成 Dialog、Adapter、Runner、HALCON 推理和 smoke 测试。

推荐拆分顺序：

1. UI 接入提示词：只做工具入口、配置对话框、参数保存回显、按钮状态、ROI 交互和未实现提示。
2. 后端和 HALCON 提示词：只做 Adapter、Runner、HALCON 模型读取/推理、错误状态、payload 和 smoke 测试。
3. 联调闭环提示词：在 UI 和后端都已存在后，连接测试运行、结果展示、工具页预览和手动验证。

分层边界：

- UI 阶段不得伪造分类算法结果；测试运行可返回明确 `backend_not_implemented` 或禁用运行按钮。
- 后端阶段不得重做 UI 布局；只通过 `ToolConfig` / `ToolRequest` / `ToolResult` 合同工作。
- 联调阶段不得改变模型格式策略；`.scbin` 仍必须返回 `unsupported_model_format`。

界面大致参考已写颜色识别、颜色比较等功能：
- 顶部标题栏、左侧参数区、右侧图像预览区、底部按钮沿用现有工具对话框风格。
- 使用 `基础 / 全部` 分段按钮。
- 左侧卡片使用既有 `panelRole=configCard`、`role=cardTitle`、`role=rowField`、`role=collapseCard` 等样式属性。
- 新增或调整注册分类 UI 时，必须遵守 `docs/FID/Function_Docs.md` 的 `FID UI 可读性和占位窗口样式规范`；旧截图或旧文档中的低对比蓝底、灰褐底和小字号要求全部作废。
- 检测区域默认全屏，支持矩形 ROI。
- 位置修正使用公共文案：`独立位置修正使能 ⓘ`、`位置修正`、`1 基准图.位置修正信息`。
- 独立位置修正使能默认关闭并禁用，直到真实补偿实现；UI tooltip 必须明确 `位置修正补偿尚未实现，当前版本默认关闭。`
- 模型训练区包含：导入模型、删除模型、导出模型。
- `注册训练` 按钮打开注册训练窗口；训练窗口可添加注册图、标注 ROI、维护分类列表、预览 ROI，并在满足训练样本条件后调用 HALCON MLP 训练 runner。
- `模型管理` 按钮打开模型管理窗口；模型管理可提供数据集创建入口并跳转注册训练窗口，但不得伪造真实数据集或真实训练。
- 模型管理窗口应使用高对比白底样式，数据集操作按钮位于数据集列表标题栏右上角；`创建数据集` 和 `导入` 应使用语义图标。
- 模型列表行操作必须使用语义图标和 tooltip，不得使用 `...`、`⇩`、`×` 等临时文本符号；tooltip 分别为 `重命名`、`导出`、`删除`。
- `创建数据集` 弹窗应包含数据集名称、注册分类训练类型、确定和取消；点击确定后进入注册训练窗口。
- 全部页参数设置按当前实现收敛为 `前K个类别` 和 `最小相似度`；模型类型和 HALCON runtime 信息不再作为该卡片必显内容。
- 结果判断包含 `类别判断`、`最低得分` 和 `判断类型`；判断类型支持 `所有检测区域输出结果为 OK`、`任意检测区域输出结果为 OK`。
- 所有普通操作按钮不得误触发 `accept`、`reject` 或程序退出。

## 注册训练窗口标签类型选择交互

`[已完成]` 标签类型列表行点击切换当前类别。

官方/规范术语：

- 标签类型列表应支持 `current item selection`（当前项选择）。
- 点击类别行主体区域应触发 `selection changed` / `current row changed` 语义。
- 被选中的类别是后续 ROI 标注的 `active class` / `current class`。
- 行内 `重命名`、`预览类别 ROI`、`删除类别` 是独立 `command action`（命令动作）。

推荐交互采用选项 A：

- 点击类别行的空白区域、标签名称或统计区域，切换 `currentClass`。
- 点击右侧行内按钮时，只执行对应按钮动作，不把按钮区域作为行点击区域处理。
- 行选中态必须立即刷新，当前类别的 ROI overlay 必须在左侧大图页同步切换。
- 若当前处于 ROI 预览页：
  - 点击其他类别行主体区域时，应切换 `currentClass` 并返回大图页，显示新当前类别在当前注册图上的 ROI。
  - 点击预览按钮时，仍按预览按钮语义进入/切换/退出 ROI 预览页。
- 若正在进行矩形或多边形 ROI 绘制，切换类别前应退出当前绘制状态，避免将后续 ROI 写入错误类别。

边界要求：

- 不修改主注册分类推理 Dialog、Adapter 或 Runner 链路。
- 不实现真实训练、真实数据集落盘或模型生成。
- 大图编辑页支持右键命中当前图、当前类别的 ROI，弹出 `删除当前 ROI` 菜单并删除单个 ROI；未命中时只显示明确状态提示，不删除任何内容。
- 预览页卡片继续支持右键删除单 ROI，删除入口必须提供清晰 tooltip/statusTip。

验收要求：

- smoke 覆盖点击类别行主体区域后切换 `currentClass`。
- smoke 覆盖切换类别后新 ROI 写入新当前类别，而不是旧类别。
- smoke 覆盖点击预览按钮仍只进入/退出 ROI 预览页。
- smoke 覆盖预览页打开时点击其他类别行主体区域返回大图并显示新类别 ROI。
- smoke 覆盖行内按钮不会误触发无关窗口关闭或程序退出。
- smoke 覆盖 ROI 预览页深色背景、标题高对比样式和删除按钮 tooltip/statusTip。
- smoke 覆盖 ROI 预览卡右键删除单个 ROI。
- smoke 覆盖大图右键命中当前类别 ROI 后删除单个 ROI，并刷新类别计数。

## ROI 交互要求

主配置对话框检测 ROI 只实现：
- `Full`
- `DetectRect`

主配置对话框要求：
- 默认检测区域为全屏。
- 点击矩形 ROI 后进入单一 ROI 编辑状态。
- 点击 `完成` 后退出 ROI 编辑状态并保留 ROI。
- ROI 必须保存、回显，并在测试运行 payload 和 overlays 中输出。
- 暂不实现自由绘制、圆形 ROI、屏蔽区域；若主配置对话框保留入口，必须返回明确未实现提示。

注册训练窗口标注 ROI 与主配置对话框检测 ROI 分开处理：

- 主配置对话框检测 ROI 仍只要求 `Full` 和 `DetectRect`，用于推理检测区域保存、回显和 overlay。
- 注册训练窗口标注 ROI 可支持 `全屏框选`、`矩形框选`、`多边形框选` 的 UI 绘制和预览。
- 注册训练窗口 ROI 按钮必须互斥；再次点击已高亮按钮时退出当前绘制状态。
- 注册训练窗口 ROI 可作为后端训练请求输入；完整数据集落盘、模型管理同步和训练按钮输出目录交互仍需按专项计划接入。

## 配置要求

通过现有 `ToolConfig.params` 和 `judgeRule` 保存配置。

建议字段：
- `params.registeredClassification.version = 1`
- `params.registeredClassification.modelPath`
- `params.registeredClassification.modelName`
- `params.registeredClassification.modelType = "halcon_mlp_registered_classification"`
- `params.registeredClassification.detectRegionType = "full" | "rectangle"`
- `params.registeredClassification.roiNormalized`
- `params.registeredClassification.enablePositionCorrection = false`
- `params.registeredClassification.positionCorrectionSource = "1 基准图.位置修正信息"`
- `params.registeredClassification.topK = 1`
- `params.registeredClassification.minSimilarity = 68`
- `params.registeredClassification.halconSoPath`
- `judgeRule.mode = "class_match" | "min_score"`
- `judgeRule.expectedLabel`
- `judgeRule.minScore`
- `judgeRule.judgeType = "all_ok" | "any_ok"`
- `judgeRule.judgeTypeText = "所有检测区域输出结果为 OK" | "任意检测区域输出结果为 OK"`

兼容要求：
- 旧配置缺少字段时给默认值。
- `ToolConfig.roiNormalized` 继续保存检测矩形 ROI；全屏为 `(0, 0, 1, 1)`。
- 保存和回显必须一致。
- 不删除已有 `params` / `judgeRule` 字段。

## 模型管理真实模型包流程

### 模型包扫描目录

模型管理窗口打开和训练完成后必须扫描：

```text

```

有效模型包目录必须同时满足：

- 包含 `metadata.json`。
- 包含 `model.gmc`。
- `readRegisteredClassificationMetadata(modelDir, &metadata)` 成功。
- `metadata.modelType == halcon_mlp_registered_classification`。
- `metadata.featureVersion == halcon_mlp_roi_stats_v1`。

### 重新训练和更新

模型管理窗口必须提供“重新训练”动作。用户选中某个模型后点击重新训练：

2. 将选中模型目录设置为更新目标：

   ```cpp

   ```

3. 训练窗口点击 `开始训练` 时，如果 `updateTargetModelDir` 非空，必须使用该目录作为 `outputModelDir`。

   ```text

5. 更新训练必须继续通过 `RegisteredClassificationTrainingRunner::train()`，依赖 runner 的 `.tmp` 写入与替换策略，失败时不得覆盖旧模型包。
6. 重新训练成功后必须刷新模型管理列表，并保持或重新选中被更新模型。
7. 如果主注册分类 Dialog 当前正在使用该模型，重新训练成功后模型路径保持不变，只更新可见状态或提示。

## 算法流程

第一版 HALCON MLP 分类训练与推理流程：

```text
训练：注册图 + 类别 + ROI
        |
        v
HALCON 图像和 ROI 域
        |
        v
提取 28 维 halcon_mlp_roi_stats_v1 特征
        |
        v
create_class_mlp / add_sample_class_mlp / train_class_mlp
        |
        v
write_class_mlp + metadata.json + training_report.json
        |
        v
推理：输入图像 cv::Mat + 检测 ROI + 模型目录
        |
        v
读取 model.gmc 和 metadata.json
        |
        v
提取同版本 ROI 特征
        |
        v
classify_class_mlp 输出预测类别、得分、TopK
        |
        v
按 judgeRule 判断 OK/NG
        |
        v
输出 ToolResult / overlays / payload
```

如果模型需要预处理参数或类别名称映射，必须优先从 HALCON 模型参数或伴随配置读取；没有可靠来源时返回明确错误，不允许猜类别。

## 结果判断要求

类别判断：
- `judgeRule.mode = "class_match"`。
- `predictedLabel == expectedLabel` 时 OK，否则 NG。
- `expectedLabel` 为空时返回 `missing_expected_label`。

最低得分：
- `judgeRule.mode = "min_score"`。
- `score >= minScore` 时 OK，否则 NG。
- `minScore` 范围限制为 0-100。

得分要求：
- `score` 统一使用 0-100。
- `scoreDirection = "higher_is_better"`。
- payload 中保留原始置信度字段，便于调试。

只修改注册训练窗口 UI 和交互闭环，控件样式继承当前窗口和项目原貌。参考用户给的图2、图3，将当前图1结构调整为：
- 左侧为大图预览区，显示当前注册图像；有标注时显示 ROI overlay，无标注时明确显示无标注状态。
- 左侧底部增加注册图缩略图列表，显示导入图片缩略图、文件名、选中状态和已标注状态。
- 缩略图状态栏使用 `全部 / 标注 / 未标注` 过滤下拉，样式与注册目标检测一致：深底浅字、高对比边框、右侧独立下拉提示区，展开列表保持高对比可读。
- 缩略图卡片使用图片预览 + 文件名/已标注状态形式；悬浮时边框高亮，右上角显示单图删除图标，点击删除该注册图及其 ROI 标注。
- 缩略图区右上角提供删除全部注册图图标，点击弹出确认提示，确认后清空注册图和 ROI 标注。
- 缩略图单图删除、删除全部等无文字图标必须设置 tooltip，文案分别为 `删除注册图`、`删除全部注册图`，并遵守 `Function_Docs.md` 的无文字控件悬浮提示规则。
- 支持上/下张或左右切换当前注册图，按循环列表语义切换。
- 点击缩略图切换大图，选中缩略图高亮。
- 右侧 `2/ 标注图像` 下方使用分类列表样式，不再使用临时表格符号。
- 分类列表显示：类别名称、目标总数/图像总数、重命名、预览/查看、删除。
- 点击某个类别的预览/查看按钮时，左侧显示该类别已标注 ROI 的预览图；点击不同类别预览图时，左侧切换对应 ROI。
- 支持 `+ 新建` 类别，创建后出现在分类列表中。
- 支持清除全部标注入口，清除当前窗口内 ROI 缓存和类别预览缓存。
- 保留 `模型类型`、`任务类型`、注册状态和 `开始训练` 按钮；满足两类样本条件后开始训练应调用 HALCON MLP 训练 runner。

## 交互要求

- `相机抓图`：从当前相机帧取图，加入缩略图列表，并显示到左侧大图。
- `外部导入`：打开图片文件选择，只允许图片格式；导入后加入缩略图列表并显示到左侧大图。
- 当前相机帧为空、图片读取失败时，在状态栏显示明确错误，不崩溃。
- 无图片时，ROI 绘制按钮不可产生有效标注，并显示请先添加注册图。
- ROI 按钮互斥；再次点击已选按钮退出绘制状态。
- 矩形和多边形 ROI 完成后，当前图片标记为已标注，并更新当前类别的目标总数/图像总数。
- 点击类别行的预览/查看图标时，左侧进入该类别 ROI 预览状态；关闭预览或切回缩略图后恢复当前图片大图。
- 删除动作至少删除当前类别在当前图片上的 ROI 缓存；如只做当前会话缓存，必须在状态栏说明。
- 清除全部标注清空当前会话内所有 ROI 缓存、已标注状态和类别预览缓存。
- 删除注册图必须同步刷新缩略图、当前图、类别计数、ROI 预览页和无图状态。

## UI 要求

- 顶部标题栏、右侧卡片、按钮边框、字体、颜色和高亮状态继承当前 `RegisteredClassificationTrainingDialog` 的样式。
- 图标按钮必须有 tooltip，不使用 `...`、`×` 这类临时文本符号作为最终操作表达。
- 分类列表行要像参考图一样能显示选中/异常或不同类别状态，但颜色应沿用当前项目高对比规则。
- 左侧底部缩略图区域应占用固定高度，不挤压右侧参数区。
- 文案以图中语义为准：`1/ 添加注册图`、`2/ 标注图像`、`分类列表`、`目标总数/图像总数`、`+ 新建`、`模型类型`、`任务类型`、`未注册`、`开始训练`。
