# 注册分类算法当前实现说明

更新时间：2026-07-10

## 当前结论

注册分类当前算法后端已经从旧的 `halcon_dl_classification` 路线切换为 HALCON 经典 MLP 分类链路。

当前有效模型类型：

```text
halcon_mlp_registered_classification
```

当前有效特征版本：

```text
halcon_mlp_roi_stats_v1
```

旧的 `halcon_dl_classification` 不再作为兼容推理分支保留；传入旧模型类型时返回 `unsupported_model_type`。海康 `.scbin` 仍不解析、不伪装兼容。

## 实现文件

核心实现文件：

- `src/algorithms/recognition/RegisteredClassificationModelPackage.h/.cpp`
  - 定义模型包元数据结构。
  - 读写 `metadata.json`。
  - 提供模型包路径 helper：`model.gmc`、`metadata.json`、`training_report.json`。
  - 校验 `modelType`、`schemaVersion`、`featureVersion`、`featureLength`、类别表等。
- `src/algorithms/recognition/RegisteredClassificationFeatureExtractor.h/.cpp`
  - 从 `cv::Mat` 输入图和归一化 ROI 提取固定 28 维特征。
  - OpenCV 仅用于图像容器和进入 HALCON 前的 8-bit BGR 连续内存桥接。
  - ROI、灰度化、阈值、区域统计、矩、灰度直方图等核心计算由 HALCON 完成。
- `src/algorithms/recognition/RegisteredClassificationTrainingRunner.h/.cpp`
  - 将训练样本提取为 28 维特征。
  - 调用 HALCON MLP 算子训练。
  - 生成完整模型包。
  - 训练失败时不覆盖旧模型目录。
- `src/algorithms/recognition/RegisteredClassificationHalconRunner.h/.cpp`
  - 读取模型包。
  - 提取运行时 ROI 特征。
  - 调用 HALCON `classify_class_mlp` 推理。
  - 输出类别、得分、TopK、OK/NG、payload 和 overlay。
- `src/tooladapters/RegisteredClassificationAdapter.cpp`
  - 从 `ToolConfig.params.registeredClassification` 和 `judgeRule` 解析配置。
  - 调用 `RegisteredClassificationHalconRunner`。
  - 转换为统一 `ToolResult`。

## 模型包结构

训练输出是一个模型目录，不是单个私有模型文件：

```text
registered_classification_model/
  model.gmc
  metadata.json
  training_report.json
```

各文件职责：

- `model.gmc`：HALCON `write_class_mlp` 写出的 MLP 分类器。
- `metadata.json`：项目侧模型元数据，保存类别表、特征版本、特征长度、阈值和训练参数。
- `training_report.json`：训练报告，保存样本统计、训练耗时、HALCON Error / ErrorLog 和 warning。

关键元数据字段：

```json
{
  "modelType": "halcon_mlp_registered_classification",
  "schemaVersion": 1,
  "featureVersion": "halcon_mlp_roi_stats_v1",
  "classLabels": [
    {"id": 0, "name": "OK"},
    {"id": 1, "name": "NG"}
  ],
  "featureLength": 28,
  "mlp": {
    "numHidden": 16,
    "maxIterations": 200,
    "randSeed": 42
  },
  "thresholds": {
    "minScore": 80,
    "rejectScore": 60,
    "top2Gap": 0
  }
}
```

## 特征提取

当前特征版本为 `halcon_mlp_roi_stats_v1`，长度固定为 28。

特征顺序：

```text
roiAspect
roiAreaRatio
foregroundAreaRatio
foregroundCenterX
foregroundCenterY
momentRa
momentRb
momentPhi
grayMean
grayMin
grayMax
grayDeviation
grayHist00
grayHist01
grayHist02
grayHist03
grayHist04
grayHist05
grayHist06
grayHist07
grayHist08
grayHist09
grayHist10
grayHist11
grayHist12
grayHist13
grayHist14
grayHist15
```

HALCON 相关流程：

1. 将输入 `cv::Mat` 转为连续 `CV_8UC3` BGR 缓冲。
2. `gen_image_interleaved` 创建 HALCON image。
3. `rgb1_to_gray` 转灰度图。
4. `gen_rectangle1` 将归一化 ROI 转为 HALCON region。
5. `reduce_domain` 限制 ROI 域。
6. `intensity` 获取灰度均值和方差。
7. `threshold` 生成前景区域。
8. `area_center` 获取前景面积和重心。
9. `moments_region_2nd` 获取二阶矩特征。
10. `gray_histo` 获取 256 灰度直方图，并压缩为 16 个归一化 bin。

异常输入：

- 空图返回 `image_empty`。
- ROI 小于最小像素尺寸返回 `invalid_roi`。
- HALCON 库不存在返回 `halcon_so_not_found`。
- HALCON 库加载失败返回 `halcon_load_failed`。
- HALCON 符号缺失返回 `halcon_symbol_missing`。

## 训练流程

训练入口：

```cpp
RegisteredClassificationTrainingRunner::train(
    const RegisteredClassificationTrainingRequest &request)
```

训练请求包含：

- `outputModelDir`：目标模型目录。
- `classLabels`：类别 ID 和类别名称。
- `samples`：训练图、归一化 ROI、类别 ID。
- `mlp`：隐藏层数量、最大迭代次数、随机种子。
- `thresholds`：`minScore`、`rejectScore`、`top2Gap`。
- HALCON runtime 路径配置。

训练校验：

- `outputModelDir` 不能为空。
- 至少 2 个类别。
- 类别 ID 非负且唯一。
- 类别名不能为空。
- 每个类别至少贡献 1 个有效样本。
- 每类少于 3 个有效样本时允许训练，但写入 warning。
- 无效样本会计入 `invalidSamplesByClass` 并跳过。

训练 HALCON 算子：

```text
create_class_mlp
add_sample_class_mlp
train_class_mlp
write_class_mlp
clear_class_mlp
```

训练写盘策略：

1. 先写入 `<outputModelDir>.tmp`。
2. 成功写出 `model.gmc`、`metadata.json`、`training_report.json` 后才替换目标目录。
3. 如果目标目录已存在，先移动到 `.bak`。
4. 临时目录替换失败时尝试恢复旧目录。
5. 训练失败或模型包不完整时清理临时目录，不覆盖上一次有效模型包。

主要训练状态：

- `ok`
- `invalid_argument`
- `invalid_class_label`
- `training_not_enough_classes`
- `halcon_so_not_found`
- `halcon_load_failed`
- `halcon_symbol_missing`
- `mlp_create_failed`
- `mlp_train_failed`
- `model_write_failed`

## 推理流程

推理入口：

```cpp
RegisteredClassificationHalconRunner::run(
    const cv::Mat &image,
    const RegisteredClassificationHalconConfig &config)
```

推理配置关键字段：

```text
modelPath
modelName
modelType = halcon_mlp_registered_classification
detectRegionType = full | rectangle
roiNormalized
topK
judgeMode = class_match | min_score
expectedLabel
minScore
```

推理流程：

1. 校验图像非空。
2. 校验 `modelPath` 非空。
3. 校验 `modelType` 必须为 `halcon_mlp_registered_classification`。
4. 读取 `metadata.json`。
5. 检查 `model.gmc` 存在。
6. 根据 `detectRegionType` 生成检测 ROI。
7. 用 `RegisteredClassificationFeatureExtractor` 提取同版本特征。
8. 校验特征长度和 `featureVersion`。
9. `read_class_mlp` 读取 MLP。
10. `classify_class_mlp` 输出 TopK 类别和置信度。
11. 根据 `metadata.classLabels` 映射类别 ID 和类别名。
12. 根据阈值和 `judgeRule` 输出 OK/NG。

推理 HALCON 算子：

```text
read_class_mlp
classify_class_mlp
clear_class_mlp
```

推理结果字段：

- `success`
- `ok`
- `status`
- `message`
- `predictedLabel`
- `predictedClassId`
- `score`
- `topClasses`
- `elapsedMs`
- `overlays`
- `payload`

payload 关键字段：

```text
algorithm
modelPath
modelName
modelType
schemaVersion
featureVersion
predictedLabel
predictedClassId
score
topClasses
detectRegionType
roiNormalized
roiPixelsRect
featureLength
elapsedMs
judgeMode
expectedLabel
minScore
rejectScore
top2Gap
trainingSampleCount
classLabels
halconSoPath
halconSoPathCandidates
positionCorrectionApplied=false
errorCode
errorMessage
```

overlay 输出：

- 检测 ROI 矩形。
- OK/NG 文本，包含预测类别、得分和耗时。

## 判定规则

推理先应用模型元数据阈值：

- `rejectScore`：Top-1 分数低于该阈值时返回 `classification_rejected`。
- `top2Gap`：Top-1 与 Top-2 分数差小于该阈值时返回 `classification_ambiguous`。

若未被拒绝或判为歧义，再应用 `judgeRule`：

- `class_match`
  - `expectedLabel` 为空返回 `missing_expected_label`。
  - 预测类别等于 `expectedLabel` 时 OK，否则 NG。
- `min_score`
  - 分数大于等于 `minScore` 时 OK，否则 NG。

## Adapter 配置解析

`RegisteredClassificationAdapter` 支持两种参数形态：

- `config.params.registeredClassification`
- 兼容旧形态：直接从 `config.params` 读取。

当前默认模型类型：

```text
halcon_mlp_registered_classification
```

`modelPath` 被视为模型目录，而不是单个 DL 模型文件。

Adapter 输出统一 `ToolResult`：

- `success`
- `ok`
- `status`
- `message`
- `score`
- `text = predictedLabel`
- `elapsedMs`
- `overlays`
- `payload`

## UI 当前接入状态

当前注册分类配置对话框已经能：

- 保存和回显主配置。
- 解析检测 ROI。
- 触发测试运行。
- 通过 adapter 调用 MLP runner。
- 显示 OK/NG、错误状态、payload 和 overlay。

注册训练窗口当前能维护：

- 注册图列表。
- 类别列表。
- 每图每类多 ROI 标注。
- ROI 预览页。
- 类别/图像/ROI 计数预览。

已暴露测试方法：

```cpp
QJsonObject RegisteredClassificationTrainingDialog::buildTrainingRequestPreviewForTest() const
```

该方法用于 smoke 验证训练窗口已有足够状态可构造训练请求。

当前 UI 训练闭环已接入：

- 训练窗口维护会话内注册图、类别和 ROI 标注。
- `开始训练` 在至少两个类别且每类有样本时启用。
- 训练窗口将会话内 `QImage` / 类别 / ROI 转换为 `RegisteredClassificationTrainingRequest`。
- 训练动作调用 `RegisteredClassificationTrainingRunner::train()`，生成 `model.gmc`、`metadata.json`、`training_report.json`。
- 训练成功后通过信号回填主配置 Dialog 的 `modelPath` / `modelName`，并使用 `halcon_mlp_registered_classification` 模型类型。

当前仍未完成的训练周边能力：

- 模型管理窗口尚未同步真实模型包列表和训练结果。
- 注册训练会话尚未落盘为可复用数据集。

后端训练 runner 和 UI 训练按钮链路已具备；缺口主要在模型管理工作流、数据集落盘和模型包导入/导出细节。

## 不支持范围

当前明确不支持：

- `halcon_dl_classification` 推理兼容。
- 海康 `.scbin` 解析。
- 自写分类器、OpenCV 分类器、ONNX、TensorRT 或其他非 HALCON 分类核心。
- 在注册分类后端内部实现模板匹配、形状模型、姿态归一化、位置修正。
- 用 `.scbin` 降级为其他算法。

位置修正当前只写入未应用 payload：

```text
positionCorrectionApplied = false
```

## 后续建议

下一步建议优先补齐训练周边能力：

1. 模型管理窗口同步真实模型包列表和训练结果。
