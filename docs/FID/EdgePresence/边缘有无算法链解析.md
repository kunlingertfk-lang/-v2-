# 边缘有无算法链解析

> 功能：边缘有无（`ToolType::EdgePresence`）  
> 核对日期：2026-07-23

## 1. 功能定位与链路

边缘有无以一条归一化搜索线和带宽构造测量矩形，优先使用 HALCON `measure_pos` 沿法线寻找边缘；Runner 中还保留 `edges_sub_pix` 的矩形 ROI 路径。

```text
ToolLibraryDialog(EdgePresence)
  -> EdgePresenceDialog
  -> ToolConfig
  -> EdgePresenceAdapter
  -> EdgePresenceHalconRunner
  -> ToolResult / overlays / payload
```

## 3. 配置合同

| 位置 | 字段 | 说明 |
| --- | --- | --- |
| `roiNormalized` | ROI/线带包围矩形 | 几何回退使用 |
| `params` | `detectRegionType` | 默认 `line_band` |
| `params` | `searchLineP1/P2` | 归一化搜索线端点 |
| `params` | `searchBandWidth` | 相对图像最大边的归一化带宽 |
| `params` | `lineBandWidthUnit` | 固定写入 `normalized_max_dimension` |
| `params` | `sensitivity` | 0..100，映射测量阈值 |
| `params` | `edgePolarity` | any/positive/negative 归一化 |
| `params` | 位置修正字段 | 保存但 Runner 未应用 |
| `params`/`judgeRule` | `judgeBasis`、`existOk` | presence 判定 |

Adapter 当前不读取自定义 `halconSoPath`，直接通过 `HalconRuntimePaths` 自动解析。

## 4. 主算法流程

1. 校验图像、`detectRegionType`、图像类型和 HALCON runtime。
2. 将搜索线和带宽转换为像素测量矩形：
   - 中点决定 `row/column`；
   - 搜索线方向转换为 HALCON `phi`；
   - 半长来自线段长度；
   - 半宽来自 `searchBandWidth * max(imageWidth,imageHeight)`。
3. 线带无效时尝试用 `roiNormalized` 构造回退测量矩形，并记录 `lineBandFallbackReason`。
4. 图像转 HALCON 灰度图。
5. `gen_measure_rectangle2` 建测量句柄。
6. `measure_pos` 按灵敏度映射后的 threshold、sigma 和极性 transition 提取边缘。
7. 读取 row、column、amplitude、distance，生成边缘点、跨线段和测量矩形 overlay。
8. 边缘数量大于零视为 found，与 `existOk` 比较得到 OK/NG。
9. 清理 measure handle 和 HALCON 对象。

保留的矩形 ROI 路径使用 `edges_sub_pix`、`length_xld`、`smallest_rectangle1_xld`；当前线带配置正常时走 `measure_pos` 路径。

## 5. HALCON 接口

核心接口：`gen_image1`、`gen_image_interleaved`、`rgb1_to_gray`、`gen_measure_rectangle2`、`measure_pos`、`close_measure`。辅助/兼容路径还使用 `edges_sub_pix`、`count_obj`、`length_xld`、`get_contour_xld`、`smallest_rectangle1_xld`。

## 6. 输出

- `count`：测得边缘数；
- `value/score`：最大幅值或归一化边缘强度；
- overlays：搜索线带、测量矩形、边缘点/线段、计数；
- payload：`measureRectangle`、`transitionUsed`、`thresholdUsed`、`sigmaUsed`、`amplitudes`、`distances`、`edgePoints`、`lineBandApplied`、`lineBandFallback*`、`maxAbsAmplitude`、`okNgReason`。

## 7. 错误与真实边界

错误：`image_empty`、`invalid_line_band`、`invalid_detect_roi`、`detect_roi_too_small`、`unsupported_detect_roi`、`unsupported_image_type`、HALCON runtime/符号/执行错误。

真实边界：

- 正式 UI 语义是线带；非矩形/线带类型不支持。
- 位置修正已实际应用于 HALCON 测量线带，详见本文末尾 2026-07-24 记录。
- mask 未实现。
- 极性在 `measure_pos` 路径映射到 transition；旧矩形 `edges_sub_pix` 路径中的部分极性说明仍标注 first version 限制。
- 超时是内部默认耗时诊断，不是可配置的强制取消。

## 8. 验证建议

当前没有独立边缘有无 smoke。应覆盖水平/垂直/斜线带、正负/任意极性、灵敏度边界、无效线带到 ROI 回退、多个边缘、无边缘、空图、HALCON 缺失以及 overlay 与测量方向一致性。
