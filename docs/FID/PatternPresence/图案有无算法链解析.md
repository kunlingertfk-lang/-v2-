# 图案有无算法链解析

> 功能：图案有无（`ToolType::PatternPresence`）  
> 文档性质：基于当前源码的实现解析，不代表所有 UI 预留项均已实现  
> 核对日期：2026-07-23

## 1. 功能定位

图案有无使用参考图中的模板区域创建 HALCON scaled shape model，再在运行图的检测区域内查找模型。输出匹配数量、最佳得分、位姿、轮廓和 OK/NG。

完整链路：

```text
ToolLibraryDialog(Presence)
  -> MainWindow::openToolConfigDialogForEdit
  -> PatternPresenceDialog
  -> ToolConfig.params / judgeRule / roiNormalized
  -> PatternPresenceAdapter
  -> PatternPresenceHalconRunner
  -> PatternPresenceHalconApi + PatternPresenceAutoModelDomain
  -> ToolResult + overlays + payload
  -> Dialog / MainWindow 结果展示
```

## 3. 配置合同

`PatternPresenceDialog::toToolConfig()` 写入：

| 位置 | 主要字段 |
| --- | --- |
| `ToolConfig.roiNormalized` | 运行图检测 ROI |
| `params` | `templateRoiNormalized`、`templateSource`、`templateImagePath`、`modelPath`、`modelAutoCreate`、`modelCacheKey` |
| `params` | `templateShapeType`、`templatePolygonNormalized`、`templateSensitivityMode`、`templateSensitivity` |
| `params` | `detectRegionType`、`enablePositionCorrection`、`positionCorrectionSource` |
| `params` | `minScore`、`polarity`、`scaleMin`、`scaleMax`、`angleStart`、`angleExtent`、`timeoutMs` |
| `params` | `showContourPoints`、`sortMode`、`judgeBasis`、`existOk`、`scoreThreshold` |
| `judgeRule` | `mode`、`existOk`、`scoreThreshold` |

Adapter 还兼容从 `params`/`judgeRule` 读取 `maxCount`、`expectedCount` 及 snake_case 别名。`minScore`、`scoreThreshold` 按 0..100 约束；角度和超时也会被边界归一化。

保存与回显由 `toToolConfig()` 和 `loadFromConfig()` 成对完成；测试时 `ToolRequest` 同时携带运行图和参考图。

## 4. Runner 算法流程

1. 校验运行图、参考图、图像类型、模板来源、模板 ROI 和检测 ROI。
2. 通过 `HalconRuntimePaths` 解析 HALCON 动态库，加载所需符号。
3. 将 `CV_8UC1/CV_8UC3/CV_8UC4` 输入桥接为 HALCON 图像，彩色图转灰度。
4. 从参考图裁取矩形或多边形模板域；自动模式可调用 `PatternPresenceAutoModelDomain`：
   - 在候选阈值上分割；
   - 做连通域、面积比例、边界接触等筛选；
   - 选择最符合目标位置和面积的建模域；
   - 自动域失败时回退到用户 ROI 建模域，并在 payload 记录原因。
5. 用 `create_scaled_shape_model` 建立模型；模型按 `toolId + modelCacheKey + 模板内容/参数` 缓存。
6. 在运行图检测域调用 `find_scaled_shape_model`，搜索角度、缩放、最低分和最大数量。
7. 读取匹配 row/column/angle/scale/score，将模型轮廓仿射到运行图，生成匹配框、轮廓和文字 overlay。
8. 根据 `judgeBasis` 判定：
   - presence：找到/未找到与 `existOk` 比较；
   - score：最佳分与 `scoreThreshold` 比较；
   - 其他值：当前仍回退 presence 语义。
9. 返回统一结果。

主要 HALCON 接口包括：`gen_image1`、`gen_image_interleaved`、`rgb1_to_gray`、`reduce_domain`、`gen_region_polygon`、`create_scaled_shape_model`、`find_scaled_shape_model`、`get_shape_model_contours`、`vector_angle_to_rigid`、`hom_mat2d_scale_local`、`affine_trans_contour_xld`。

## 5. 输出合同

`ToolResult` 映射：

| 字段 | 来源 |
| --- | --- |
| `success` | Runner 是否完成算法执行 |
| `ok` | 判断规则结果 |
| `status/message` | 执行状态和诊断信息 |
| `text` | 结果摘要 |
| `score` | 最佳匹配得分 |
| `count` | 匹配数量 |
| `elapsedMs` | 总耗时 |
| `overlays` | 检测 ROI、匹配框、模型轮廓、结果文字 |
| `payload` | 使用参数、HALCON 路径、各阶段耗时、匹配列表、自动建模域诊断、回退原因 |

关键 payload 包括 `matches`、`matchScores`、`bestRow/Column/Angle/Scale/Score`、`modelCacheHit`、`modelBuildMs`、`findMs`、`detectRoiPixels`、`templateRoiPixels`、`autoModelDomain*`、`okNgReason`、`timeoutExceeded`。

## 6. 异常与边界

明确错误状态包括：

- `image_empty`、`reference_image_empty`
- `unsupported_image_type`
- `unsupported_template_source`
- `invalid_template_roi`、`invalid_template_polygon`、`unsupported_template_roi`
- `invalid_detect_roi`、`invalid_detect_polygon`、`unsupported_detect_roi`
- `halcon_so_not_found`、`halcon_load_failed`、`halcon_symbol_missing`
- `create_scaled_shape_model_failed`、HALCON 异常和超时诊断

Adapter 捕获标准异常和未知异常，避免异常穿透工具链。

## 7. 当前真实边界

- 实际模板来源只支持 `referenceImage`；模板文件、外部模型路径虽有字段，但 Runner 返回 unsupported，不会静默替代。
- 模板 ROI 支持矩形和多边形；检测 ROI 当前支持矩形/多边形代码路径，圆等其他形状不支持。
- 位置修正已接入公共 Consumer 和 HALCON Region 路径，详见本文末尾 2026-07-24 记录。
- `sortMode` 已读取，但 `sortModeApplied=false`。
- `maxCount` 会限制 HALCON 返回的匹配数；`expectedCount` 当前只进入配置/payload，不参与最终 OK/NG。
- 超时主要是运行后诊断 `timeoutExceeded`，不是对 HALCON 调用的强制中断。
- OpenCV 仅用于输入容器、裁剪/调试图和桥接；核心建模匹配由 HALCON 完成。

## 8. 验证现状与建议

当前未发现独立的图案有无 smoke 工程。后续回归至少覆盖：

1. 新建、保存、重开回显矩形/多边形模板和检测 ROI。
2. 正样本、负样本、低分、数量边界和“有为 OK/无为 OK”。
3. 自动建模域成功、自动域失败回退、模型缓存命中和模板变化重建。
4. 空图、空参考图、非法 ROI、不支持来源、HALCON 动态库/符号/license 异常。
5. overlay 坐标与原图一致，payload 中匹配位姿、得分和耗时可追踪。
## 2026-07-24 位置修正接入

- Dialog 通过公共 `PositionCorrection` 读写开关、显示文本和稳定来源 ID，基础/全部页的开关与来源按 ID 同步。
- Dialog 测试通过 `PositionCorrectionDialogTestHelper` 执行当前工具之前的方案前缀，注册模板定位、位置修正和图案有无 Adapter，不再以空运行上下文孤立测试。
- Adapter 使用 `PositionCorrectionConsumer::resolve()`；来源缺失、上游未匹配、矩阵或尺度非法时明确失败，不回退固定 ROI。
- Runner 在整图坐标创建矩形/多边形基准 Region，经 HALCON `affine_trans_region`、`clip_region` 后 `reduce_domain`，匹配坐标不再叠加局部裁图偏移。
- 运行 Overlay 使用同一矩阵输出 `detect_roi`、匹配轮廓和匹配原点；Dialog 检测到运行态 ROI 后清除配置态 ROI。
- Dialog 已提供 PC 图片离线测试，支持静态图重复运行、ROI 修改后重测和退出清理。
- 验证：主工程影子 qmake/make 通过；`presence_ocr_position_correction_contract_smoke` 与公共位置修正 smoke 通过。
