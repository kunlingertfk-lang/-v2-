# 斑点有无算法链解析

> 功能：斑点有无（`ToolType::BlobPresence`）  
> 核对日期：2026-07-23

## 1. 功能定位与链路

斑点有无在检测区域内按灰度范围分割连通域，再用面积范围筛选 Blob，依据是否存在进行 OK/NG 判断。

```text
ToolLibraryDialog(BlobPresence)
  -> BlobPresenceDialog
  -> ToolConfig
  -> BlobPresenceAdapter
  -> PositionCorrectionConsumer（可选）
  -> BlobPresenceHalconRunner
  -> ToolResult / overlays / payload
```

这是六个有无类中当前唯一把公共位置修正上下文实际传入 Runner 并变换检测区域的功能。

## 3. 配置合同

| 位置 | 字段 | 含义 |
| --- | --- | --- |
| `roiNormalized` | 矩形/形状包围区域 | 检测主 ROI |
| `params` | `detectRegionType` | `rect`、`polygon`、`circle` 等 UI 类型 |
| `params` | `detectPolygonNormalized` | 多边形点 |
| `params` | `detectCircleNormalized` | 圆心、半径、包围矩形 |
| `params` | 位置修正字段 | `enablePositionCorrection`、`positionCorrectionSource` 及公共序列化字段 |
| `params` | `grayMin/grayMax/invertRange` | 灰度阈值区间及反选 |
| `params` | `areaMin/areaMax` | Blob 面积筛选 |
| `params` | `maskOutputEnabled` | 预留 mask 输出 |
| `params` | `judgeBasis/existOk` | 判定方式 |
| `params` | `timeoutMs` | 超时诊断阈值 |
| `judgeRule` | `mode/existOk` | 判定规则镜像 |

Adapter 对灰度限制到 0..255，面积和超时限制为非负。

## 4. 算法流程

1. Adapter 校验工具类型，解析 HALCON 路径和 JSON 参数。
2. 若启用位置修正，通过 `resolvePositionCorrectionForConsumer()` 从工具链运行上下文获取上游结果；无法解析时返回明确位置修正错误。
3. Runner 校验图像、ROI、灰度区间、面积区间和 HALCON runtime。
4. 图像转 HALCON 灰度图。
5. 生成矩形、多边形或圆形检测域；应用位置修正时通过 HALCON affine transform 变换区域。
6. `reduce_domain` 限定检测域。
7. 正常区间使用 `threshold(grayMin, grayMax)`；反选区间通过两侧阈值区域合并实现。
8. `connection` 拆分连通域，`select_shape(area)` 按面积筛选。
9. 读取每个 Blob 的面积、中心和最小外接矩形，生成 ROI、Blob 框和统计 overlay。
10. `count > 0` 得到 presence，再与 `existOk` 比较得出 `ok`。

主要 HALCON 接口：`gen_image*`、`rgb1_to_gray`、`gen_rectangle1`、`gen_region_polygon`、`gen_circle`、`affine_trans_region`、`reduce_domain`、`threshold`、`union2`、`connection`、`select_shape`、`area_center`、`smallest_rectangle1`。

## 5. 输出

结果包含：

- `score`：以检测结果统计形成的归一化表现值；
- `count`：筛选后的 Blob 数；
- overlays：检测 ROI、位置修正轮廓/原点（启用时）、Blob 外接框、统计文字；
- payload：`blobCount`、`blobAreas`、`centers`、`boundingRects`、`largestArea`、`averageArea`、`totalArea`、`areaRate`、阈值/面积实际值、ROI 几何、位置修正状态、HALCON 路径和耗时。

## 6. 错误状态

- `image_empty`
- `invalid_detect_roi`、`invalid_detect_polygon`、`invalid_detect_circle`
- `unsupported_detect_roi`
- `invalid_gray_range`、`invalid_area_range`
- `unsupported_image_type`
- `halcon_so_not_found`、`halcon_load_failed`、`halcon_symbol_missing`
- 位置修正来源缺失、上游结果无效或公共解析失败
- `BlobPresence HALCON error`

## 7. 当前真实边界

- Runner 代码已实现矩形、多边形、圆形检测域；某些旧错误文案仍写着 free/circle/polygon 未实现，属于文案与当前实现演进不完全同步，应以实际分支和 smoke 结果为准。
- `maskOutputEnabled` 会保存和进入 payload，但 `maskOutputApplied=false`，不会产出真实 mask。
- 判定实质是 presence + `existOk`；`judgeBasis` 目前没有扩展出独立计数范围规则。
- 超时为耗时诊断，不保证中断 HALCON 算子。
