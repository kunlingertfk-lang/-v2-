# 位置修正原始截图清单

用户提供的位置修正原始截图直接保存在上一级 `docs/FID/PositionCorrection/` 目录。原图不得裁剪、缩放后覆盖、调色或添加二次标注。

截图已按 `1.png` 至 `7.png` 提供。本目录只维护场景映射，不移动、不复制原图。

| 编号 | 固定文件名 | 场景 | 主要比对内容 |
| --- | --- | --- | --- |
| PC-UI-01 | `../1.png` | 基准图位置修正说明态 | 位置修正开关、说明文字、启用/未启用示意区 |
| PC-UI-02 | `../2.png` | 基准图模板区域设置态 | 测试运行、开关、模板区域设置、矩形/多边形与完成按钮 |
| PC-UI-03 | `../3.png` | 工具库位置修正入口 | 定位工具分类、位置修正图标、选中区域与确认/取消 |
| PC-UI-04 | `../4.png` | 独立位置修正配置窗口 | 基础/全部、订阅基准范围、三项运行值、创建基准、预览区 |
| PC-UI-05 | `../5.png` | 输出字段绑定菜单 | 上游工具分组、输出字段二级菜单、字段绑定图标 |
| PC-UI-06 | `../6.png` | 工具列表多个位置修正实例 | 多实例编号、基准图标签、选中态、OK/NG 区和设置入口 |
| PC-UI-07 | `../7.png` | 其他工具选择修正来源 | 独立位置修正使能、基准图与多个位置修正来源菜单 |

进行 UI 对照时，应同时检查：

- `../1.png` 至 `../7.png` 均存在且可打开。
- Markdown 引用保持使用上述相对路径。
- 原图尺寸和内容与用户提供版本一致。
- 红色矩形等用户原始标注属于参考内容，不应从原图中删除。
