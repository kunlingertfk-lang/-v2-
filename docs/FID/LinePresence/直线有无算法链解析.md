# 直线有无算法链解析

> 功能：直线有无（`ToolType::LinePresence`）  
> 核对日期：2026-07-23

## 1. 功能定位与链路

直线有无在用户绘制的线带中使用 HALCON metrology line 测量并拟合直线，按命中点、长度、拟合误差和直线度筛选候选，最后做存在性判断。

```text
ToolLibraryDialog(LinePresence)
  -> LinePresenceDialog
  -> ToolConfig
  -> LinePresenceAdapter
  -> LinePresenceHalconRunner
  -> ToolResult / overlays / payload
```

| 位置 | 字段 |

| `params` | `detectRegionType=line_band` |

Adapter 将 `sensitivity`、`lineDegree` 限制到 0..100；极性和边缘选择文本会归一化。HALCON 路径使用自动解析，不读取自定义路径字段。

## 4. 主算法流程

1. 校验图像、检测区域类型、图像类型和 HALCON runtime。
2. 将线带端点转像素坐标，计算中心、方向、测量半长和半宽；无效线带回退到 `roiNormalized`。
3. 图像转 HALCON 灰度图。
4. `create_metrology_model` 创建测量模型。
5. `add_metrology_object_line_measure` 加入期望直线。
6. 将 UI 参数映射到 HALCON：
   - sensitivity -> threshold、最小命中数等；
   - lineDegree -> 允许拟合误差、直线度阈值；
   - edgePolarity -> transition；
   - edgeType -> select（first/last/strongest）。
7. `set_metrology_object_param` 设置参数，`apply_metrology_model` 执行。
8. `get_metrology_object_measures` 读取采样点，`get_metrology_object_result` 读取拟合直线。
9. 计算线长、角度、命中数、拟合误差、直线度和综合分，筛选有效候选。
10. 输出直线端点/采样点/文字 overlay，以有效直线数量和 `existOk` 判定。

Runner 后半还保留 `edges_sub_pix + segment_contours_xld + fit_line_contour_xld` 的候选提取路径，用于矩形 ROI/兼容场景。

## 5. HALCON 接口

主路径使用：

- `create_metrology_model`
- `add_metrology_object_line_measure`
- `set_metrology_object_param`
- `apply_metrology_model`
- `get_metrology_object_measures`
- `get_metrology_object_result`
- `clear_metrology_model`

辅助路径使用 `edges_sub_pix`、`segment_contours_xld`、`fit_line_contour_xld`、`length_xld`、`get_contour_xld`。

## 6. 输出

| 输出 | 含义 |
| --- | --- |
| `count` | 有效直线候选数 |
| `score` | 最佳直线综合分 |
| `value` | 最佳直线长度等测量值 |
| overlays | 线带、拟合直线、端点、采样点、计数文字 |
| payload | `lines`、`rawLineCandidates`、`rejectedLines`、`bestLineLength`、`bestLineScore`、`hitCount`、`fitError`、`angleDeg`、`thresholdUsed`、`transitionUsed`、`selectUsed`、`lineBandFallback*`、`okNgReason` |

## 7. 错误与真实边界

错误包括 `image_empty`、`invalid_line_band`、`invalid_detect_roi`、`detect_roi_too_small`、`unsupported_detect_roi`、`unsupported_image_type`、HALCON 加载/符号/运行异常，以及 `fit_error_above_line_degree_max` 等候选拒绝原因。

真实边界：

- UI 的主要有效区域是线带；其他自由形状未实现。
- `edgeType=manual` 没有手工候选数据，Runner 回退 strongest，并记录 `manualUnsupported=true`。
- 位置修正已实际应用于 HALCON 计量线域；mask 仍未实现。
- 超时为内部耗时诊断。
- `lineDegree` 不是几何角度，而是对直线拟合质量/直线度的 UI 抽象参数。
