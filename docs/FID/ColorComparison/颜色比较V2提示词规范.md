## 固定边界

```text
这是对现有颜色比较工具的 V2 升级，不是从零新增工具。
不得重复新增 ToolType、工具库入口或无关公共 UI。
核心视觉与比较必须使用 HALCON；OpenCV 只用于 cv::Mat、显示、桥接和测试图生成。
颜色比较采用独立 V2 提取路径，本轮不修改颜色识别现有评分行为。
固定特征为 32×32 H/S 联合直方图，layout=hue_major。
histo_2dim(Region, H, S) 必须解释为 row=Hue、column=Saturation。
相似度固定使用 HALCON tuple_min2 + tuple_sum 直方图交集，同分布必须为 100 分。
禁止 C++ Gaussian kernel、主峰经验权重、伪 Bhattacharyya 和 OpenCV compareHist 生产旁路。
“光照补偿”是受限亮度归一化，不是把 V 通道差异加入扣分。
位置修正只留接口；UI 禁用，运行不应用，并输出 warning。
色谱特征禁用；旧配置请求时返回 unsupported_feature。
V1 模型必须重新取样，不能转置裸数组或静默回落。
基础/全部只能控制显隐，不得改变配置或模板状态。
```

## 标准执行提示词

```markdown
按照 `docs/superpowers/plans/2026-07-13-color-comparison-v2.md` 实施颜色比较 V2。

执行前完整阅读：
- `AGENTS.md`
- `docs/FID/Function_Docs.md`
- `docs/FID/ColorComparison/颜色比较V2设计说明.md`
- `docs/superpowers/specs/2026-07-13-color-comparison-v2-design.md`
- `docs/superpowers/plans/2026-07-13-color-comparison-v2.md`

要求：
- 使用 TDD，每个任务先写失败测试，再做最小实现。
- 保留当前工作树中的用户改动，不修改无关文件。
- 所有视觉与相似度核心使用 HALCON，不引入新的非 HALCON 算法依赖。
- 不修改颜色识别既有行为；其 H/S 轴问题单独登记。
- 灰度输入不能只检查归一化后的 BGR Mat；必须传递原始像素格式元数据。
- 显式 licensed smoke 遇到 license 缺失必须失败，不能返回跳过成功。
- 构建使用 build/ 影子目录，不提交构建产物。
- 完成后更新颜色比较实现记录，写明验证命令、输出和仍受阻项。
```

## 评审提示词

```markdown
只读评审颜色比较 V2，按以下顺序检查：

1. 输入来源元数据是否能区分 Mono8 与彩色灰/白目标。
2. V1 是否只能 stale/unsupported 后重新取样。
3. 模型是否严格校验 1024 维、有限、非负、归一化和 hue_major。
4. histo_2dim 是否按 row=Hue、column=Saturation 展平。
5. 正式评分是否只使用 HALCON tuple 算子并保证同分布 100。
6. 是否残留 C++ soft-kernel、主峰覆盖、伪 Bhattacharyya 或 OpenCV compareHist。
7. 光照补偿是否为受限归一化并输出 scale/clippedRatio。
8. 基础/全部、检测 ROI、灵敏度、阈值是否错误清空模板。
9. 参考图、模板 ROI/Mask 和提取参数是否正确使模型 stale。
10. 当前帧是否只绘制检测 ROI，不叠加参考图模板 ROI。
11. 色谱和位置修正是否明确禁用/预留，而非静默降级。
12. 默认 smoke 与 licensed smoke 是否明确分离，license #2036 是否仍被如实报告。

输出按 P0/P1/P2 排序，给出文件和行号，不直接修改源码。
```

## 验证提示词

```markdown
验证颜色比较 V2，不修改源码：

- 运行 model/contract smoke。
- 运行 offscreen Dialog smoke。
- 使用 build/ 影子目录执行 qmake 和 make。
- 显式运行 RUN_HALCON_LICENSED_SMOKE=1 的算法 smoke。
- 检查同图 100、H/S 轴、红色回绕、联合分布、多色比例、ROI/Mask 和光照补偿。
- 检查灰度来源 NG、不支持位深、坏模型、V1、色谱和位置预留状态。
- 执行 git diff --check 和 git status --short，确认没有构建产物或无关改动。

若 HALCON license 仍报 #2036，结论必须写“licensed 数值验证阻塞”，不得写“全部通过”。
```
