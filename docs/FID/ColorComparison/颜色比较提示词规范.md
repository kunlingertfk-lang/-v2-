在 `ColorComparisonAdapter` 中：
- 仅支持 `ToolType::ColorComparison`。
- 从 `ToolConfig.params.colorComparison` 和 `judgeRule` 解析 runner 配置。
- 使用 `HalconRuntimePaths::resolveHalconLibPath()` 解析 HALCON runtime。
- 调用 `ColorComparisonHalconRunner`。

- 错误必须返回明确 `status` 和 `message`，不允许崩溃。

## HALCON Runner 要求

核心算法必须在 `ColorComparisonHalconRunner` 中实现。

实现前必须确认本机 HALCON 环境具备以下符号：
- `gen_image_interleaved`
- `decompose3`
- `trans_from_rgb`
- `gen_rectangle1`
- `gen_circle`
- `T_gen_region_polygon_filled`
- `difference`
- `T_area_center`
- `reduce_domain`
- `T_gray_histo_range`
- `T_tuple_min2`
- `T_tuple_sum`
- `clear_obj`

若 runtime、license 或必要符号缺失：
- 返回 `halcon_so_not_found`、`halcon_load_failed` 或 `halcon_symbol_missing`。
- 不允许 fallback 到 OpenCV 或自写算法。

算法：
- 将 `cv::Mat` 转为 8-bit BGR。
- 用 HALCON 转 HSV。
- 对模板 ROI 提取 H/S 或 H/S/V 直方图。
- 对检测 ROI 提取 H/S 或 H/S/V 直方图。
- 使用直方图交集相似度：
  - `intersection = sum(min(templateFeature, detectFeature))`
  - `normalizer = min(sum(templateFeature), sum(detectFeature))`
  - `similarity = normalizer > 0 ? intersection / normalizer : 0`
  - `score = clamp(similarity * 100, 0, 100)`
- `score >= minScore` 判定 OK，否则 NG。
