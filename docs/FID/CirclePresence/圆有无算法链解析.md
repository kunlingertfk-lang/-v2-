# 圆有无算法链解析

> 功能：圆有无（`ToolType::CirclePresence`）  
> 核对日期：2026-07-24

## 1. 功能定位与链路

圆有无在 ROI 中分割候选区域，通过面积、圆度和最小外接圆筛选圆形目标，最后按存在性判断。

```text
ToolLibraryDialog(CirclePresence)
  -> CirclePresenceDialog
  -> ToolConfig
  -> CirclePresenceAdapter
  -> CirclePresenceHalconRunner
  -> ToolResult / overlays / payload
```

## 2. 文件地图

- UI：`src/CirclePresenceDialog.{h,cpp}`、`ui/CirclePresenceDialog.ui`
- Adapter：`src/tooladapters/CirclePresenceAdapter.{h,cpp}`
- Runner：`src/algorithms/presence/CirclePresenceHalconRunner.{h,cpp}`
- 入口和运行：`src/ToolLibraryDialog.cpp`、`src/MainWindow.cpp`

Dialog 内部注册独立测试 Adapter/ToolEngine，可运行参考图或相机帧，并保存 `ToolPreviewSnapshot`。

## 3. 配置合同

| 位置 | 字段 |
| --- | --- |
| `roiNormalized` | 检测 ROI/形状包围矩形 |
| `params` | `detectRegionType`、`detectPolygonNormalized`、`detectCircleNormalized` |
| `params` | `sensitivity`、`roundness`、`edgePolarity`、`edgeType` |
| `params` | `enablePositionCorrection`、`positionCorrectionSource` |
| `params` | `judgeBasis`、`existOk`、`timeoutMs` |
| `judgeRule` | `mode`、`existOk` |

Adapter 将灵敏度和圆度约束到 0..100，解析矩形/多边形/圆形几何。

## 4. 算法流程

1. 校验输入、ROI、图像类型和 HALCON 动态库。
2. 图像桥接为 HALCON 灰度图。
3. 根据配置创建矩形、多边形或圆形检测区域；启用位置修正时，先用修正矩阵变换 ROI，再裁剪到图像范围并 `reduce_domain`。
4. 灵敏度映射到阈值 margin，按极性执行亮/暗阈值；`any` 路径允许多轮候选。
5. `connection` 拆分区域。
6. 依次按面积和 `circularity` 筛选，圆度阈值由 `roundness` 与 `sensitivity` 共同映射。
7. 对候选调用 `smallest_circle`，读取圆心、半径、面积、圆度和强度指标。
8. `edgeType` 选择候选；manual 当前回退 strongest。
9. 生成检测 ROI、候选圆、最佳圆和文字 overlay。
10. `finalCircleCount > 0` 与 `existOk` 比较得到 OK/NG。

主要 HALCON 接口：`gen_image*`、`rgb1_to_gray`、`gen_circle`、`gen_region_polygon_filled`、`affine_trans_region`、`intersection`、`reduce_domain`、`threshold`/`binary_threshold`、`connection`、`select_shape`、`circularity`、`area_center`、`smallest_circle`。

位置修正链路：

1. Dialog 保存稳定的修正来源 ID，并在测试时通过完整前缀工具链运行来源工具。
2. `CirclePresenceAdapter` 通过公共 `PositionCorrectionConsumer` 解析修正上下文。
3. Runner 使用 HALCON 仿射变换检测区域，且同步变换 ROI overlay。
4. 修正上下文缺失、来源无效或变换失败时返回明确错误，不静默退回未修正 ROI。

## 5. 输出

主要字段：

- `count`：最终圆数量；
- `score`：最佳候选强度/圆形质量的归一化值；
- overlays：ROI、候选/最佳圆、计数文字；
- payload：`rawCircles`、`circles`、`bestCircle`、`rawCircleCount`、`finalCircleCount`、`circularityMinUsed`、`threshold*Used`、`edgeTypeUsed`、`manualUnsupported`、`okNgReason`、`timeoutExceeded`。
- 启用位置修正后还会输出 `positionCorrectionApplied`、修正来源、矩阵和修正前后 ROI 等诊断字段。

## 6. 错误与边界

错误包括 `image_empty`、无效矩形/多边形/圆形 ROI、`unsupported_detect_roi`、`detect_roi_too_small`、`unsupported_image_type`、HALCON 路径/加载/符号错误和 HALCON 执行异常。

当前边界：

- 矩形、多边形、圆形检测域已有实际代码路径；历史 `todo`/`maskReason` 文案不可当作唯一实现依据。
- 位置修正已接入矩形、多边形、圆形检测域；变换后的区域会裁剪到当前图像范围。
- `edgeType=manual` 没有配套选择数据，回退 strongest，并在 payload 标记。
- mask、caliper 模式没有完整接入；payload 会说明是否应用。
- 判断仅按 presence/`existOk`，`judgeBasis` 尚未形成额外规则。
