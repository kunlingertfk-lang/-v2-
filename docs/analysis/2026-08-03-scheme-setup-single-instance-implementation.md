# 方案设置流程窗口单实例实施文档

## 理解复述

- 目标：解决主窗口中“方案设置”双击或连续点击后，可以同时产生多个相机参数、基准图、工具流程或输出窗口的问题。
- 输入：主窗口的“方案设置”和“工具设置”入口，以及方案编辑页之间的导航。
- 输出：同一个 `MainWindow` 下任何时刻最多只有一个活动的方案编辑窗口；重复点击只激活已有窗口，不创建新窗口。
- 边界：不改变相机、基准图、工具和输出页的业务行为，不改变工具配置保存语义，不调整相机线程。

## 根因

1. `MainWindow::openCameraParamsDialog()` 每次执行都无条件 `new CameraParamsDialog(this)`。
2. `PlanDialogUtils::showDialogFromWidget()` 通过 `show()` / `showMaximized()` 非模态显示，主窗口仍可继续接收点击。
3. `MainWindow` 没有记录当前方案编辑窗口，也没有重复入口防护。
4. 多个相机参数窗口可分别导航到工具页，因此最终可见多个工具流程窗口。

## 信息缺口与假设

- 已确认：按钮信号只连接一次，不是重复 `connect` 导致。
- 默认假设：方案编辑四个页面属于同一条会话，页面切换后仍应占用同一个单实例名额。
- 默认假设：重复点击时优先把已有窗口置顶和获取焦点，而不是静默忽略。

## 执行抓手

1. 在 `MainWindow` 中增加 `QPointer<QWidget>`，记录当前活动的方案编辑窗口。
2. 增加“注册活动窗口”和“激活已有窗口”接口；指针在窗口销毁后自动置空。
3. `PlanDialogUtils::showWindowFromWidget()` 显示方案编辑页时，把新页注册到所属 `MainWindow`；使相机 → 基准图 → 工具 → 输出的切换始终跟踪当前页。
4. `openCameraParamsDialog()` 和 `openToolsDialog()` 创建窗口前先尝试激活已有页；若成功则立即返回。
5. 保留现有 `WA_DeleteOnClose` 生命周期，不引入手工 delete，避免悬空指针和重复释放。

## 验证方式

1. 自动化：扩展 `tools_dialog_actions_smoke`，验证连续打开方案设置只存在一个活动设置页，并能激活已有页。
2. 导航回归：切换到基准图或工具页后重复点击主窗口入口，不新建第二个页面。
3. 关闭回归：关闭方案编辑流程后可再次正常打开。
4. 构建：执行 `qmake ../../qt_ui_test.pro` 和 `make -j4`。
5. 手工：快速双击、连续多击“方案设置”，确认始终只有一个方案编辑流程窗口。

## 实施与验证记录

- 已在 `MainWindow` 增加活动方案编辑窗口的 `QPointer` 跟踪与激活接口。
- 已在 `PlanDialogUtils` 中统一注册相机、基准图、工具和输出页，导航切换会更新当前页。
- 主窗口的方案设置和工具设置入口在创建新窗口前会优先激活已有页。
- `tools_dialog_actions_smoke`：通过，已覆盖重复入口、导航后跟踪新页和隐藏页释放活动状态。
- 主工程 `qmake ../../qt_ui_test.pro && make -j4`：通过。
- 相关文件 `git diff --check`：通过。
