# 注册分类训练上下文持久化与重新训练恢复设计

## 背景

当前注册分类模型管理已经能够记录真实模型包，并将选中模型目录作为重新训练的输出目录，但训练窗口的注册图、类别、ROI 和图像名称只存在于窗口内存。关闭训练窗口后再次点击“重新训练”，窗口无法恢复上次训练基础。

## 目标

- 新训练模型包保存完整的注册分类训练上下文。
- 从模型管理点击“重新训练”时恢复上次的注册图、图像名称、类别名称和 ROI。
- 重新训练成功后更新同一模型目录，模型路径保持不变。
- 重新训练失败时不破坏已有可用模型和训练上下文。
- 旧模型包没有训练上下文时仍可使用，并以明确提示打开空白训练窗口。

## 非目标

- 不引入数据库、远端模型仓库或独立全局数据集管理。
- 不改变 HALCON MLP 特征、分类器和推理协议。
- 不恢复上次窗口的临时选择态，例如当前缩略图、当前 ROI 选中项和当前预览页。
- 不为缺少历史上下文的旧模型伪造训练数据。

## 模型包格式

新模型包增加以下目录：

```text
ModelFiles/RegisteredClass/yyyyMMdd/model_HHmmss_zzz/
├── model.gmc
├── metadata.json
├── training_report.json
└── training_session/
    ├── session.json
    └── images/
        ├── image_0001.png
        └── image_0002.png
```

`session.json` 使用版本化 JSON，至少包含：

- `schemaVersion`
- `classes`: 按训练类别顺序保存类别名称。
- `images`: 每张图的 `name`、`relativePath`、`width`、`height` 和 `marksByClass`。
- 每个 ROI 标注的 `classId`、`type`、`rect` 和可选 `polygon`。

图像使用 PNG 副本并通过 `relativePath` 引用，路径只能位于当前 `training_session/images/` 目录内。写入和读取必须校验路径不越出训练上下文目录，避免错误路径或恶意模型包导致越界访问。

## 保存流程

训练请求仍由 `RegisteredClassificationTrainingDialog` 根据内存会话生成，核心训练仍只调用 `RegisteredClassificationTrainingRunner::train()`。

训练输出采用临时目录：

1. 将当前会话中的图像写入临时 `training_session/images/`。
2. 写入临时 `training_session/session.json`。
3. 调用 runner 将 `model.gmc`、`metadata.json` 和 `training_report.json` 写入同一临时模型包。
4. 所有文件成功后，使用现有模型目录替换策略一次性替换目标目录。
5. 任一步骤失败，删除临时目录，保留原模型目录。

新增模型使用日期模型目录；重新训练使用模型管理传入的原模型目录。更新不能改变模型目录名，也不能先清空原模型目录再开始训练。

## 恢复流程

模型管理点击“重新训练”后：

1. 创建 `RegisteredClassificationTrainingDialog`。
2. 设置更新目标模型目录。
3. 读取并校验 `training_session/session.json`。
4. 加载其引用的 PNG 图像，恢复类别、图像名称和所有 ROI 标注。
5. 刷新缩略图、类别列表、ROI overlay 和训练就绪状态。

恢复失败时必须保留训练窗口可操作，并显示明确原因。部分图像加载失败时不得静默丢失；应提示失败数量和文件名，并禁止直接覆盖更新模型，直到用户补充或删除无效样本后重新满足训练条件。

## 旧模型兼容

没有 `training_session/session.json` 的旧模型：

- 仍显示在模型管理中并可用于推理。
- 点击“重新训练”时显示“该模型没有历史训练数据，请重新添加注册图和 ROI”。
- 训练窗口以空白会话打开。
- 用户补充有效的至少两个类别样本后，可以覆盖更新原模型并生成新的训练上下文。

存在上下文但版本不支持、JSON 损坏、图像缺失或路径非法的模型：

- 模型仍可用于推理。
- 重新训练窗口显示不可恢复原因。
- 不自动删除或改写原模型包。

## 界面行为

- 重新训练窗口状态栏显示当前更新目标模型名及恢复状态。
- 可恢复时显示已恢复的图像数、类别数和 ROI 数。
- 无上下文或恢复失败时显示明确提示。
- 训练成功后模型管理刷新原模型行，主注册分类 Dialog 保持原模型目录并更新模型名称/状态。

## 测试

增加回归覆盖：

- 训练请求可将类别、图像名称和 ROI 序列化到 `session.json`。
- 训练成功的模型包同时包含分类器、元数据、训练报告和训练上下文图片。
- 从模型目录恢复后，训练请求的类别、图像数量、样本数量和 ROI 与保存前一致。
- 旧模型无上下文时可打开空白训练窗口并显示提示。
- 上下文图片缺失或路径越界时恢复失败，不覆盖原模型。
- 重新训练成功后仍使用同一模型目录，并保留完整模型包文件。
- 运行注册分类 smoke、主 Qt shadow build 和 `git diff --check`。
