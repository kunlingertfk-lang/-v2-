# 注册分类 ROI 预览页与多 ROI 标注设计

## 背景

注册分类训练窗口已具备注册图缩略图、分类列表、新建类别、会话内 ROI 缓存、类别重命名和基础 ROI 预览状态。当前实现仍以“每张图每类别一个 ROI”为主，点击类别预览只在左侧大图显示当前类别 ROI overlay，没有切换到参考图中的 ROI 预览页。

本次目标是按参考图继续完善训练窗口 UI 交互：点击某类别预览时，左侧显示该类别所有 ROI 的预览图；删除类别时删除该类别及其 ROI；同时把 ROI 数据升级为多 ROI 列表。

## 目标

- 每张注册图、每个类别支持多个 ROI 标注。
- 新绘制一次矩形或多边形 ROI 时追加到当前图、当前类别的 ROI 列表，而不是覆盖旧 ROI。
- 左侧大图上显示当前图、当前类别的 ROI，并在每个 ROI 左上角显示序号。
- 点击分类列表某类别的预览按钮后，左侧切换为该类别 ROI 预览页。
- 预览页以卡片展示该类别所有 ROI 裁剪图，卡片显示来源图名和 ROI 编号。
- 再次点击同一类别预览按钮或点击预览页关闭按钮，返回当前注册图大图。
- 点击另一类别预览按钮时，直接切换到另一类别的 ROI 预览页。
- 预览页支持选中某个 ROI 卡片，右键弹出菜单删除该单个 ROI。
- 类别删除按钮：
  - 类别数大于 1 时，删除该类别和该类别所有 ROI。
  - 只剩 1 个类别时，保留默认类别，只清空该类别所有 ROI。

## 数据模型

将当前 `TrainingImageState::marksByClass` 的 value 从单个 ROI 状态升级为 ROI 列表：

```text
TrainingRoiMark
  - type: "full" | "rect" | "polygon"
  - rect: QRectF
  - polygon: QVector<QPointF>

TrainingImageState
  - image: QImage
  - name: QString
  - marksByClass: QMap<int, QVector<TrainingRoiMark>>
```

统计规则：

- `目标总数`：该类别在所有注册图中的 ROI 总数。
- `图像总数`：至少含有该类别一个 ROI 的注册图数量。
- 缩略图 `已标注`：该注册图任一类别任一 ROI 存在。
- 状态栏 `标注 N`：所有类别所有注册图的 ROI 总数。

类别删除后的索引重排：

- 删除类别 `k` 后，所有图片中 `marksByClass` 里大于 `k` 的类别索引减 1。
- `currentClass` 变为可用范围内的最近类别。
- 若只剩一个类别，则不删除类别名，只清空该类别所有 ROI。

## 预览页交互

预览页进入：

- 点击类别行的预览按钮。
- 如果当前没有在预览该类别，左侧进入预览页。
- 如果当前已经在预览该类别，再次点击该按钮返回大图。
- 如果正在预览其他类别，直接切换为新类别预览页。

预览页内容：

- 顶部显示：`<类别名> | 已标注目标：N`。
- 右上角显示关闭按钮，点击返回当前注册图大图。
- 卡片区域显示该类别所有 ROI 裁剪图。
- 卡片文案格式：`<来源图名> #<编号>`。
- 矩形 ROI 裁剪矩形区域。
- 多边形 ROI 使用外接矩形裁剪。
- full ROI 使用整图缩放预览。
- 无 ROI 时显示：`当前类别暂无 ROI 标注`。

预览页删除单个 ROI：

- 点击 ROI 卡片后该卡片进入选中态。
- 右键选中卡片弹出菜单，提供 `删除当前 ROI`。
- 删除后只移除该卡片对应 ROI。
- 删除后刷新预览页卡片、类别统计、缩略图已标注状态和状态栏。
- 删除最后一个 ROI 后，预览页显示空状态。

## 大图编辑页交互

- 返回大图后显示当前注册图。
- 当前图、当前类别的多个 ROI 均显示在画布上。
- 每个 ROI 左上角显示编号。
- 新绘制 ROI 时追加到当前类别列表。
- 本次不实现大图 overlay 点击选中 ROI，也不实现大图右键删除单个 ROI。

## 后续优化

- 可后续扩展为在大图 overlay 上点击选中某个 ROI，并支持右键删除该单个 ROI。
- 该优化需要在 `FrameViewHelper` 或训练窗口 overlay 层增加 ROI 命中检测与选中态绘制，不纳入本次实现。
