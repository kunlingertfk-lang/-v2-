# 注册训练缩略图过滤与目标检测 ROI 删除设计

## 背景

注册目标检测训练窗口已经将缩略图区升级为 `全部 / 标注 / 未标注` 过滤下拉、缩略图卡片、单图删除和删除全部注册图。注册分类训练窗口仍使用普通 `QListWidgetItem` 缩略图，视觉和交互不统一。注册目标检测已支持 ROI 新增、编号和预览，但 ROI 预览页缺少删除单个 ROI 的入口。

## 方案

- 注册分类训练窗口复用注册目标检测缩略图区交互形态：深底浅字过滤下拉、右侧独立下拉提示区、缩略图卡片、hover 高亮、单图删除和删除全部确认。
- 注册分类缩略图过滤使用会话内映射，不改变真实图片列表顺序；`全部` 显示所有注册图，`标注` 显示任一类别有 ROI 的注册图，`未标注` 显示无 ROI 的注册图。
- 注册图删除只影响训练窗口会话态：删除图片及其 ROI 标注，刷新当前图、类别计数、缩略图、预览页和无图状态，不接入真实数据集落盘。
- 注册目标检测 ROI 删除采用预览页卡片删除语义：每个 ROI 卡片右上角提供删除图标，删除后刷新 ROI 卡片、编号、目标计数和缩略图标注状态。
- 不实现大图 overlay 点击选中或直接删除 ROI；该能力复杂度更高，后续另起设计。

## 验收

- `registered_classification_dialog_smoke` 覆盖注册分类训练缩略图过滤、缩略图卡片、单图删除入口和删除全部入口。
- `registered_classification_detection_dialog_smoke` 覆盖注册目标检测 ROI 预览卡片删除。
- 主工程 `qmake && make` 通过。
