# 注册分类训练窗口提示词更新设计

## 背景

`docs/FID/RegisteredClassification/注册分类提示词规范.md` 早期以“第一版推理闭环”为主，仍包含“注册图像窗口只做占位”“注册训练按钮只能打开占位窗口”“暂不实现自由绘制”等旧边界。当前注册分类已经完成主工具推理闭环，并已接入注册训练窗口的抓图、外部导入、矩形 ROI 和多边形 ROI 的 UI 交互闭环。旧提示词会和后续按参考图继续调整训练窗口的目标冲突，需要先整理提示词规范。

本次只修改提示词规范文档，不修改代码，不修改实现记录文档。

## 目标

把提示词规范升级为“推理闭环 + 注册训练窗口 UI 交互闭环”的当前阶段描述，并新增一段可直接复制使用的“注册训练窗口二阶段 UI 修改提示词”。

二阶段提示词要指导后续实现按用户提供的参考图调整注册训练窗口：

- 左侧保留大图预览区，并支持显示当前注册图像或对应类别 ROI 预览。
- 左侧底部增加注册图缩略图列表，显示导入图片、选中状态和已标注状态。
- 支持图片间切换，切换关系按循环列表语义描述。
- 右侧标注区改为分类列表样式，显示类别名、目标总数/图像总数和行内操作。
- 支持新建类别入口。
- 行内操作使用语义图标和 tooltip，包括重命名、查看/预览当前类别 ROI、删除当前 ROI 或类别相关标注。
- 支持清除全部标注入口。
- 保留模型类型、任务类型、注册状态和开始训练按钮。
- 控件样式继承当前项目原貌，不重新设计一套风格。

## 范围

In:

- 更新“第一版固定范围”中的阶段边界，避免继续把注册训练窗口描述为纯占位。
- 更新 UI 阶段提示词中关于注册训练、模型管理、标注 ROI 的描述。
- 区分主配置对话框检测 ROI 与注册训练窗口标注 ROI。
- 新增注册训练窗口二阶段 UI 修改提示词。
- 保留 HALCON 红线、`.scbin` 不支持策略、非 HALCON 算法禁入和真实训练不接入的限制。

Out:

- 不修改 `RegisteredClassificationDialog`、`RegisteredClassificationTrainingDialog` 或任何 C++ 代码。
- 不修改 `registered_classification_function_implementation.md`。
- 不规划真实 HALCON 训练、真实数据集落盘、模型生成或 `.scbin` 支持。
- 不重写主对话框推理、Adapter、Runner 或 smoke 测试要求。

## 文档结构设计

提示词规范采用局部升级，不整篇重写：

1. 固定上下文保持稳定，只在必要处说明训练窗口当前可做 UI 交互闭环。
2. “第一版固定范围”改为“当前阶段固定范围”，保留已完成推理闭环，并纳入训练窗口 UI 闭环。
3. “UI 实现提示词”中删除或改写“注册训练/模型管理只能占位”的冲突句子。
4. “ROI 交互要求”拆分为主配置对话框检测 ROI 与注册训练窗口标注 ROI。
5. 文末新增“注册训练窗口二阶段 UI 修改提示词”，用于本次后续代码实现。

## 约束

- 提示词必须继续强调所有视觉核心算法遵守 HALCON 约束。
- OpenCV 仍只允许作为图像载体、显示或格式桥接。
- 训练窗口 UI 可展示 ROI 和缩略图，但不得宣称已完成真实训练、真实数据集落盘或模型生成。
- 控件样式要沿用现有训练窗口和项目控件风格；图标、按钮、表格和状态反馈只做结构与交互调整。
- 普通按钮不得误触发 `accept`、`reject` 或程序退出。

## 验收

- 文档中不再出现与当前目标冲突的“注册训练窗口只能占位”“注册图像窗口不得接入标注 UI”类要求。
- 文档明确主配置对话框检测 ROI 与训练窗口标注 ROI 的边界。
- 新增提示词能直接指导后续按参考图修改训练窗口。
- 文档仍明确真实训练、数据集落盘、`.scbin` 支持和非 HALCON 分类算法不在本次范围。
