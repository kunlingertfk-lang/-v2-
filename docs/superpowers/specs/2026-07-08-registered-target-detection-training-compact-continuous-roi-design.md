# 注册目标检测训练窗口压缩布局与连续 ROI 设计

## 背景

注册目标检测训练窗口已经对齐注册分类训练窗口样式，并具备添加注册图、矩形/多边形目标标注、ROI 编号、目标列表和训练参数开关。当前右侧 `添加注册图`、`标注图像`、检测专属参数区仍占用较多高度；ROI 框选按钮需要明确为连续绘制开关模式。

## 范围

本次只调整 `RegisteredClassificationDetectionTrainingDialog` 及其 smoke/规范：

- 更新注册目标检测提示词规范。
- 调整右侧训练面板布局密度。
- 明确并验证 ROI 连续框选模式。
- 不修改 `RegisteredClassificationTrainingDialog`。
- 不新增真实训练、数据集落盘、Adapter 或 Runner。

## 设计

### 右侧布局

右侧面板保持现有卡片顺序：

```text
1/ 添加注册图
2/ 标注图像
目标列表
检测专属参数
底部状态 + 开始训练
```

布局要求：

- `添加注册图` 卡片减少上下 padding 和内部 spacing，按钮仍保持可点击高度。
- `标注图像` 卡片减少上下 padding，标注说明和 ROI 按钮紧凑排列。
- `目标列表` 保留适当空白，参考注册分类分类列表，但不使用拉伸因子无限撑高。
- 检测专属参数卡片紧跟目标列表，减少大块空白；两个开关行保持清晰可读。
- 底部状态文案和 `开始训练` 按钮保持在右侧底部区域。

### ROI 连续框选

ROI 按钮是连续绘制开关：

- 点击 `矩形框选` 后按钮保持高亮，进入连续矩形 ROI 绘制模式。
- 在该模式下可以连续绘制多个矩形 ROI。
- 绘制完成后不自动退出矩形 ROI 绘制模式，按钮仍保持高亮。
- 再次点击 `矩形框选` 后退出矩形 ROI 绘制模式，按钮取消高亮。
- `多边形框选` 同理。
- `矩形框选` 与 `多边形框选` 互斥；切换到另一个模式时，原按钮取消高亮并关闭原绘制模式。
- 无图时点击 ROI 按钮提示 `请先添加注册图`，并不进入高亮状态。

### 状态提示

保留现有状态文案：

- 当前相机帧为空但成功获取基准图时显示 `当前图像帧为空，已获取基准图`。
- 绘制 ROI 后继续显示已添加 ROI 的状态，例如 `已添加矩形目标 ROI`。

## 验收

- smoke 覆盖点击 `矩形框选` 后按钮 checked。
- smoke 覆盖绘制矩形 ROI 后按钮仍 checked，可继续绘制。
- smoke 覆盖再次点击 `矩形框选` 后按钮 unchecked，并退出绘制。
- smoke 覆盖矩形/多边形互斥。
- smoke 覆盖绘制 ROI 后目标计数更新、ROI 编号标签存在。
- 主工程 `qmake && make` 通过。
