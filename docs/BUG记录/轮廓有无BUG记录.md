## CP-20260805-01 2026-08-05 14:46 CST — “运行显示轮廓点”开关样式异常

### 基本信息

- 修复时间：2026-08-05 14:50 CST
- 状态：已修复，构建通过，待手工视觉复测
- 严重程度：低
- 影响控件：`basicShowContourSwitch`、`showContourSwitch`
- 来源任务：排查颜色识别 ROI 不全 BUG（019fcfba-e665-7811-84d6-4499935942db）

### 问题现象

轮廓有无基础页的“运行显示轮廓点”显示为橙色方块和深色残块，基础页与全部页的同一开关外观不一致。

### 根因

`basicShowContourSwitch` 没有加入既有滑动开关选择器，回退并混用了普通 `QCheckBox` 样式；背景、indicator 与状态图层发生叠加。

### 修复方案

1. 将基础页和全部页两个控件同时纳入 `ContourPresenceDialog` 精确选择器。
2. 控件固定为 54 × 28、透明且无边框。
3. 关闭和开启分别使用 `toggle-off.svg` 与 `toggle-on.svg`。
4. 保留原有基础/全部页状态同步逻辑。

### 验证记录

- `git diff --check`：通过。
- `qmake` 与 `make -j4`：通过。
- 尚需手工检查两页显示、状态同步和禁用状态。
