# 方案设置重复点击产生多个工具流程窗口

## 基本信息

- 发现日期：2026-08-03
- 状态：已修复
- 影响模块：主界面、方案设置导航、相机参数页、基准图页、工具页、输出页
- 相关入口：主界面“方案设置”、“工具设置”

## 问题现象

在主界面快速双击或连续多次点击“方案设置”后，程序会创建多个相机参数窗口。这些窗口可以分别继续导航到基准图、工具或输出页，最终导致同时存在多个工具流程窗口。

潜在影响：

- 多个窗口同时编辑同一方案，可能相互覆盖配置。
- 多个页面同时订阅相机帧和基准图信号，增加资源消耗和生命周期风险。
- 用户无法确定哪个窗口代表当前有效的方案编辑会话。

## 复现步骤

1. 登录并进入主界面。
2. 快速双击或连续多次点击“方案设置”。
3. 观察出现多个相机参数窗口。
4. 在不同窗口中点击“工具”，可继续生成多个工具流程窗口。

## 根因

1. `MainWindow::openCameraParamsDialog()` 每次都无条件执行 `new CameraParamsDialog(this)`。
2. `PlanDialogUtils::showDialogFromWidget()` 使用 `show()` / `showMaximized()` 非模态显示方案编辑页，主窗口仍可继续接收点击。
3. `MainWindow` 没有跟踪当前活动的方案编辑窗口，也没有重复入口防护。
4. 按钮信号只连接了一次，本问题不是重复 `connect` 导致。

## 修复方案

1. 在 `MainWindow` 中使用 `QPointer<QWidget>` 跟踪当前活动的方案编辑页。
2. 主界面的“方案设置”和“工具设置”入口创建窗口前，先检查已有页面；已存在时只执行置顶和激活。
3. `PlanDialogUtils` 在显示相机、基准图、工具或输出页时，将新页注册为当前活动页，保证导航后仍对整条流程生效。
4. 页面关闭、隐藏或销毁后清理活动状态，允许用户再次正常打开。
5. 保留原有 `WA_DeleteOnClose` 生命周期，不引入手工删除。

## 修复后行为

- 双击或连续点击“方案设置”时，始终只有一个方案编辑流程窗口。
- 若当前已经切换到基准图、工具或输出页，重复点击会激活该当前页，不会回到相机页或创建新页。
- 关闭方案编辑流程后，可以再次正常打开。
