## CAL-20260805-01 2026-08-05 14:46 CST — 标定位姿与运行位姿开关样式异常

### 基本信息

- 修复时间：2026-08-05 14:50 CST
- 状态：已修复，构建通过，待手工视觉复测
- 严重程度：低
- 影响控件：`calibrationPoseEnabled`、`runPoseEnabled`
- 来源任务：排查颜色识别 ROI 不全 BUG（019fcfba-e665-7811-84d6-4499935942db）

### 问题现象

标定转换页的“标定位姿修正使能”和“运行位姿修正使能”本应显示为滑动开关，却出现整条深色背景，与浅色参数区不一致。

### 根因

两个控件本质上是 `QCheckBox`。旧规则只处理 indicator，控件本体仍受到普通复选框背景规则影响，导致滑动开关和深色长条叠加。

### 修复方案

1. 将样式严格限定到 `CalibrationTransformDialog` 的 `poseGroup`。
2. 控件本体设为透明、无边框，并保留说明文字。
3. indicator 统一为 54 × 28；关闭和开启分别使用 `toggle-off.svg` 与 `toggle-on.svg`。
4. 禁用态降低文字对比度。

- `qmake` 与 `make -j4`：通过。
- 尚需手工检查关闭、开启和禁用状态。
